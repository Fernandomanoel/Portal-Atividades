🎯 Objetivo

Você vai criar um programa que:

  1. Peça um número ao usuário
  2. Mostre a tabuada desse número (de 1 a 10)
  3. Conte quantos resultados são pares
  4. Some todos os resultados
  5. No final:
    • Diga se a soma é maior que 100
    • Pergunte se o usuário quer repetir o programa

🚀 O que você vai treinar

  • ✅ Variáveis
  • ✅ Funções
  • ✅ if / else
  • ✅ for
  • ✅ while
  • ✅ Operações matemáticas
  • ✅ Acumuladores
  • ✅ Estrutura de repetição com controle
