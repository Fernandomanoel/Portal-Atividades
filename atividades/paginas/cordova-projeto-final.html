    1. O Plano de Hoje

    Seu app já faz tudo: adiciona, exclui, marca como feita, busca, ordena, salva no localStorage e roda no emulador. Hoje é resolver desafios que faltam, escolher pelo menos 4, e fechar o projeto com um código de referência completo.

    4. Desafio: Renomeie o App fácil

    Troque "Minhas Missões" por outro tema — os nomes de variável no JS podem continuar iguais por dentro:

    • 📚 "Minha Lista de Leitura" com ícone book;
    • 🎬 "Filmes Pra Assistir" com ícone film;
    • 🎮 "Jogos Pra Zerar" com ícone game-controller.

    Troque o <ion-title>, o name="add-circle" do ícone do botão, e o placeholder do campo de texto pra combinar com o novo tema.

    5. Desafio: Badge com Contador Dinâmico médio

    Código

    No index.html, dentro do <ion-toolbar>, depois do <ion-title>:

    www/index.html<ion-badge id="badge-pendentes" slot="end" color="danger">0</ion-badge>

    No index.js, dentro de desenharLista():

    6. Desafio: Editar uma Missão Existente médio

    Código

    Adicione um botão de edição antes do de excluir, no template de desenharLista():

    www/js/index.js<ion-button slot="end" color="primary" fill="clear" onclick="editarMissao(${indice})"> <ion-icon name="pencil" slot="icon-only"></ion-icon> </ion-button>
    www/js/index.js — nova funçãofunction editarMissao(indice) { const novoTexto = prompt("Editar missão:", missoes[indice].texto); if (novoTexto !== null && novoTexto.trim() !== "") { missoes[indice].texto = novoTexto; desenharLista(); } }

    prompt(mensagem, valorInicial) abre uma caixa de texto pronta do navegador, já preenchida com o texto atual. Se a pessoa cancelar, novoTexto vira null — por isso o if confere isso antes de salvar.

    7. Desafio: Ordenar Pendentes Primeiro médio

    Código
    www/js/index.jsfunction ordenarPorStatus() { missoes.sort((a, b) => a.feita - b.feita); // false (0) vem antes de true (1) desenharLista(); }

    Truque de JavaScript: false - true vira 0 - 1 = -1, e sort usa esse número negativo/positivo pra decidir a ordem. Pendentes (false) sobem pro topo.

    8. Desafio: Animação ao Adicionar difícil

    Código
    www/css/index.css@keyframes entrarSuave { from { opacity: 0; transform: translateY(-10px); } to { opacity: 1; transform: translateY(0); } } ion-item { animation: entrarSuave 0.3s ease; }

    Todo <ion-item> novo (inclusive quando a lista inteira é redesenhada) entra com um pequeno deslize suave em vez de aparecer seco. Repare no efeito ao adicionar uma missão nova.

    9. Desafio: Limpar Todas as Concluídas difícil

    Código — adicione um botão com id="btn-limpar"
    www/js/index.jsdocument.getElementById('btn-limpar').addEventListener('click', () => { const confirmou = confirm("Remover todas as missões já concluídas?"); if (confirmou) { missoes = missoes.filter(m => !m.feita); // mantém só as NÃO concluídas desenharLista(); } });

    filter() aqui reconstrói o array inteiro, mantendo só quem passa no teste (!m.feita) — as concluídas simplesmente não entram no novo array.

    10. Código de Referência Completo

    Se quiser conferir seu projeto contra uma versão de referência (com os desafios fáceis e médios já aplicados):

    www/js/index.js — completoconst campoMissao = document.getElementById('campo-missao'); const botaoAdicionar = document.getElementById('btn-adicionar'); const listaNaTela = document.getElementById('lista-missoes'); let missoes = JSON.parse(localStorage.getItem('minhas_missoes')) || []; function desenharLista() { localStorage.setItem('minhas_missoes', JSON.stringify(missoes)); const pendentes = missoes.filter(m => !m.feita).length; document.getElementById('badge-pendentes').innerText = pendentes; listaNaTela.innerHTML = ""; missoes.forEach((missao, indice) => { const estilo = missao.feita ? "text-decoration:line-through;color:#999" : ""; listaNaTela.innerHTML += ` <ion-item> <ion-label style="${estilo}" onclick="alternarFeita(${indice})">${missao.texto}</ion-label> <ion-button slot="end" color="primary" fill="clear" onclick="editarMissao(${indice})"> <ion-icon name="pencil" slot="icon-only"></ion-icon> </ion-button> <ion-button slot="end" color="danger" fill="clear" onclick="excluirMissao(${indice})"> <ion-icon name="trash" slot="icon-only"></ion-icon> </ion-button> </ion-item> `; }); } botaoAdicionar.addEventListener('click', () => { const texto = campoMissao.value; if (texto.trim() !== "") { missoes.push({ texto: texto, feita: false }); desenharLista(); campoMissao.value = ""; } }); function alternarFeita(indice) { missoes[indice].feita = !missoes[indice].feita; desenharLista(); } function editarMissao(indice) { const novoTexto = prompt("Editar missão:", missoes[indice].texto); if (novoTexto !== null && novoTexto.trim() !== "") { missoes[indice].texto = novoTexto; desenharLista(); } } function excluirMissao(indice) { const confirmou = confirm("Excluir esta missão?"); if (confirmou) { missoes.splice(indice, 1); desenharLista(); } } desenharLista(); // desenha a lista salva assim que o app abre

    11. Testando Tudo Junto

    Rode cordova run browser e passe por todo o fluxo, do início ao fim:

    1. Adicione 5 missões diferentes;
    2. Marque 2 como concluídas;
    3. Edite o texto de 1;
    4. Exclua 1;
    5. Recarregue a página — as outras 3 devem continuar exatamente como estavam;
    6. Rode cordova run android e repita o teste dentro do celular virtual.

    12. Preparando pra Apresentar

    Separe, pra mostrar seu projeto:

    • O app aberto no navegador (cordova run browser);
    • O app aberto no celular virtual (cordova run android), com pelo menos 3 missões cadastradas;
    • Uma frase curta explicando o que cada parte faz — treine dizer em voz alta, é a melhor forma de fixar o que você aprendeu.
