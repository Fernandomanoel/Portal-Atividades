🕹️ O que é a Godot Engine

A Godot Engine é um motor de jogos (game engine): um programa que já traz pronto tudo aquilo que todo jogo precisa — uma tela para desenhar personagens e cenários, um sistema de física, controle de entrada do teclado e mouse, sons, e uma linguagem de programação para dar vida a tudo isso. Em vez de programar um jogo do zero em uma linguagem qualquer, você monta o jogo dentro da Godot, usando as ferramentas que ela já oferece.

Por que usamos a Godot no curso

  • Gratuita e de código aberto — não é preciso pagar licença nem assinatura para usar, mesmo em jogos comerciais.
  • Leve e rápida de instalar — o programa todo cabe em poucos megabytes, roda em Windows, Linux e Mac.
  • Boa para 2D e 3D — hoje vamos trabalhar em 2D, que é o ponto de partida ideal para entender os conceitos.
  • Usa GDScript, uma linguagem de programação própria, parecida com Python, criada para ser fácil de aprender.

Jogos famosos feitos com Godot incluem Brotato e Cassette Beasts. É uma ferramenta profissional, usada por estúdios reais — não é um "programa de brinquedo".

🧭 Entendendo a interface do editor

Antes de sair clicando, vale entender as três áreas que você vai usar o tempo todo dentro da Godot. Quase tudo que fazemos nesta atividade acontece nelas:

🌳 Árvore de Cena (Scene Tree)

Fica geralmente no canto superior esquerdo. Um jogo na Godot é organizado em cenas, e cada cena é formada por Nodes (nós) organizados em árvore — um dentro do outro, como pastas dentro de pastas. Cada Node é um "pedaço" do jogo: um personagem, um texto na tela, um som, uma colisão. É aqui que você adiciona, renomeia e organiza esses nós.

🔧 Inspector

Fica no canto direito. Mostra as propriedades do Node que está selecionado na árvore de cena: posição, tamanho, cor, texto, imagem, entre outras. É clicando e digitando aqui que você ajusta como cada elemento do jogo se comporta e aparece — sem precisar escrever código para isso.

🖼️ Viewport (área central)

É o "palco" do jogo: mostra visualmente o que está sendo montado, exatamente como vai aparecer quando o jogo rodar. Você pode clicar e arrastar os objetos diretamente aqui.

📁 FileSystem

Fica no canto inferior esquerdo. Lista os arquivos do seu projeto: as cenas salvas (.tscn), imagens, scripts, etc. É como o Explorador de Arquivos, mas só para os arquivos do seu jogo.

💡 Guarde essa ideia: Node = peça do jogo, Cena = conjunto de Nodes organizados, Inspector = onde você ajusta cada peça. Todo o resto da atividade é aplicação direta desses três conceitos.

1️⃣ Criando o projeto

Todo trabalho na Godot começa dentro de um projeto — uma pasta que guarda todas as cenas, scripts e imagens do seu jogo.

  1. Abra o Godot Engine.
  2. Na tela inicial (Project Manager), clique em New Project (Novo Projeto).
  3. No campo de nome, digite: Meu Primeiro Projeto
  4. Escolha uma pasta no computador para salvar o projeto e clique em Create & Edit. O editor da Godot vai abrir com o projeto vazio.

2️⃣ Criando a primeira cena

Uma cena vazia ainda não tem nenhum Node. Precisamos criar o primeiro — o que vai servir de "raiz" (o node mais de cima na árvore, dentro do qual todos os outros vão morar).

  1. Clique no símbolo + no topo do painel de Scene Tree.
  2. Na lista de tipos de Node, selecione Node2D.
  3. Renomeie o Node para: CenaPrincipal
  4. Salve a cena com Ctrl + S. Quando pedir o nome do arquivo, use: CenaPrincipal.tscn

Por que Node2D e não outro tipo?

A Godot tem dezenas de tipos de Node, cada um com uma função: alguns desenham imagens, outros tocam som, outros calculam física. O Node2D é o tipo mais básico para jogos em 2 dimensões — ele só sabe que existe em algum lugar do espaço (tem uma posição, uma escala e uma rotação), sem fazer mais nada sozinho. Por isso é ideal como "raiz" da cena: todos os outros Nodes 2D que colocarmos dentro dele (como o Sprite2D e o Label a seguir) herdam esse comportamento de posicionamento.

3️⃣ Adicionando um personagem

Agora vamos colocar algo visível na tela: uma imagem, usando o Node responsável por desenhar imagens.

  1. Com CenaPrincipal selecionado, clique em + para adicionar um filho (Add Child Node).
  2. Escolha o tipo Sprite2D — é o Node que existe justamente para exibir uma imagem 2D na tela.
  3. Com o Sprite2D selecionado, olhe para o painel Inspector à direita.
  4. Localize a propriedade Texture e clique em <vazio> ao lado dela para escolher uma imagem disponível no seu computador ou no projeto.

Assim que a imagem for escolhida, ela aparece na Viewport. Esse é o fluxo básico da Godot: adicionar um Node → configurar suas propriedades no Inspector.

4️⃣ Movendo objetos

Um jogo raramente tem os objetos parados no mesmo lugar — então vamos praticar a movimentação manual, direto na tela.

  1. Clique no Sprite2D para selecioná-lo (ele fica com um contorno amarelo na Viewport).
  2. Use a ferramenta de movimentação (a seta com quatro pontas, no topo da Viewport, ou tecla W).
  3. Arraste o objeto com o mouse para experimentar diferentes posições:
    • Centro da tela
    • Canto superior esquerdo
    • Canto inferior direito

5️⃣ Alterando propriedades no Inspector

Arrastar com o mouse é rápido, mas impreciso. Para um controle exato, usamos os campos numéricos do Inspector. Com o Sprite2D ainda selecionado, procure o grupo Transform e altere cada campo, anotando o que muda visualmente:

PropriedadeO que ela realmente faz
Position X / Position YMove o objeto no eixo horizontal (X) e vertical (Y). Valores de X maiores empurram para a direita; valores de Y maiores empurram para baixo (na Godot, o eixo Y cresce para baixo, ao contrário do que se aprende em matemática).
Scale X / Scale YRedimensiona o objeto. 1.0 é o tamanho original; 2.0 deixa duas vezes maior; 0.5 deixa a metade do tamanho. Um valor negativo espelha a imagem.
RotationGira o objeto em torno do seu próprio centro. O valor é um ângulo — na Godot, o Inspector já mostra em graus, então basta digitar, por exemplo, 45 para uma rotação de 45°.
📝 Anote em uma folha (ou nos comentários da entrega) o resultado visual de cada alteração que você testou — isso mostra que você entendeu o efeito de cada propriedade, não só que copiou os passos.

6️⃣ Adicionando um texto

Vamos agora adicionar um segundo tipo de Node: um que exibe texto na tela em vez de imagem.

  1. Com CenaPrincipal selecionado, adicione um novo Node do tipo Label.
  2. No Inspector, encontre a propriedade Text e digite: Meu Primeiro Projeto no Godot
  3. Usando a mesma ferramenta de movimentação do passo anterior, posicione o texto no topo da tela.

Repare que o Label também tem Position, Scale e Rotation — porque ele também é, por baixo dos panos, um tipo de Node2D. Esse é o poder da árvore de cena: os mesmos conceitos valem para qualquer objeto.

7️⃣ Executando o projeto

  1. Pressione F5 (ou clique no botão Run Project, o triângulo de "play" no canto superior direito).
  2. Na primeira vez, a Godot vai perguntar qual cena deve ser executada — selecione CenaPrincipal.tscn como cena principal.
  3. Uma janela se abre mostrando seu jogo rodando: o personagem e o texto exatamente como você configurou.

✅ O que você deve ter ao final

Um projeto chamado Meu Primeiro Projeto, com uma cena CenaPrincipal.tscn contendo um Node2D raiz, um Sprite2D com imagem, e um Label com o texto "Meu Primeiro Projeto no Godot", rodando ao apertar F5.
