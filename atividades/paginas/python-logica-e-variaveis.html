Python — Variáveis, input() e f-strings

← Voltar para Python

🎯 Objetivo

Entender variáveis, aprender a receber dados digitados pelo usuário com input(), saber por que quase sempre é preciso converter o que o usuário digita, e conhecer as f-strings — um jeito mais legível de montar mensagens.

🧠 Como todo programa "pensa"

Quase todo programa de computador segue a mesma lógica básica, em três etapas:

1. Receber informações → 2. Processar essas informações → 3. Mostrar o resultado

Nesta atividade você vai praticar exatamente essas três etapas: receber dados com input(), processá-los guardando e (quando precisar) convertendo em variáveis, e mostrar o resultado com print().

📦 O que é uma variável?

Pense numa variável como uma caixa com um nome escrito nela. Você guarda um valor dentro da caixa, e sempre que quiser usar aquele valor de novo, basta chamar a caixa pelo nome — sem precisar digitar o valor de novo.

caixa "nome"
"Ana"
caixa "idade"
17
exemplonome = "Ana" idade = 17
  • nome e idade são os nomes das caixas (as variáveis);
  • o sinal = não significa "igual" como na matemática — significa "guarde este valor dentro desta caixa";
  • depois disso, sempre que você escrever nome no código, o Python vai usar "Ana" no lugar.

Uma coisa importante: o conteúdo da caixa pode trocar a qualquer momento — daí o nome "variável". Se você escrever idade = 18 mais adiante, a caixa passa a guardar 18 no lugar de 17.

⌨️ input() — pedindo informação ao usuário

O input() é usado quando o programa precisa fazer uma pergunta e esperar o usuário digitar uma resposta no teclado. O programa "pausa" até a pessoa digitar algo e apertar Enter.

exemplonome = input("Digite seu nome: ") print("Olá,", nome)
  • input() → mostra o texto entre aspas na tela e espera o usuário digitar algo;
  • "Digite seu nome: " → a mensagem/pergunta que aparece no terminal (repare no espaço antes do fim das aspas — deixa a digitação mais confortável);
  • nome = → guarda o que o usuário digitou dentro da variável nome;
  • a vírgula dentro do print() → separa texto fixo e variáveis, exatamente como você já viu na atividade anterior.

⚠️ input() sempre devolve texto — cuidado com números!

Aqui está o ponto mais importante desta atividade, e é um erro muito comum de quem está começando: tudo que o usuário digita com input() chega ao programa como texto (tipo str) — mesmo que a pessoa digite só números.

Por que isso importa? Se você tentar somar dois valores vindos direto de um input(), o Python não vai fazer uma conta — ele vai colar os textos um no outro. Se a pessoa digitar 5 e 3, o resultado de "5" + "3" é "53", não 8!

Para transformar o texto digitado em um número de verdade, você precisa converter o valor usando uma destas funções:

🔄 Funções de conversão

  • int() → transforma o texto em número inteiro (sem casas decimais). Ex.: idade, quantidade de itens;
  • float() → transforma o texto em número decimal (com vírgula/ponto). Ex.: altura, preço, nota.
exemplo — convertendo idadeidade = int(input("Digite sua idade: ")) print("Você tem", idade, "anos")
  • primeiro o Python executa o input(...) mais interno, que pega o texto digitado;
  • esse texto entra dentro de int( ), que o transforma em número inteiro;
  • só depois disso o resultado (já número) é guardado na variável idade.

É como embrulhar uma função dentro da outra: de dentro para fora, primeiro pergunta (input), depois converte (int ou float), e só então guarda na variável.

✨ f-strings — um jeito mais legível de montar texto

Até agora você separou textos e variáveis no print() usando vírgulas. Existe um jeito mais moderno e legível: as f-strings. Você coloca um f antes das aspas, e pode escrever as variáveis direto dentro do texto, entre chaves { }.

comparação# Com vírgula (como você já viu): print("Olá,", nome, "! Você tem", idade, "anos.") # Com f-string (mais legível): print(f"Olá, {nome}! Você tem {idade} anos.")
  • o f logo antes das aspas avisa o Python: "esta string tem variáveis dentro dela";
  • cada {variavel} é substituído pelo valor daquela variável na hora de mostrar o texto;
  • o resultado final é exatamente igual ao da versão com vírgulas — só que mais fácil de ler, principalmente quando a frase é grande.
Dica: à medida que as frases forem ficando maiores, prefira f-strings. Elas deixam o código bem mais parecido com a frase final que vai aparecer na tela.

✅ Exercícios práticos

Crie um arquivo .py novo para cada exercício, e teste rodando (botão direito > Run Python File in Terminal). A dificuldade sobe aos poucos — não pule etapas.

Exercício 1 · Nome do usuário

Crie ola_nome.py que pergunte o nome da pessoa e mostre Olá, [nome]! usando f-string.

nome = input("Digite seu nome: ") print(f"Olá, {nome}!")
Exercício 2 · Cidade onde mora

Crie minha_cidade.py que pergunte a cidade onde o aluno mora e mostre Você mora em [cidade].

cidade = input("Em que cidade você mora? ") print(f"Você mora em {cidade}.")
Exercício 3 · Em que ano você fará 100 anos?

Crie cem_anos.py que pergunte o nome e a idade da pessoa, converta a idade para número com int(), calcule em quantos anos ela completa 100 anos, e mostre uma frase final com f-string.

nome = input("Qual é o seu nome? ") idade = int(input("Quantos anos você tem? ")) faltam = 100 - idade print(f"{nome}, faltam {faltam} anos para você completar 100 anos!")

Esse exercício só funciona porque a idade foi convertida com int() — sem a conversão, a linha 100 - idade daria erro, pois o Python não sabe subtrair um número de um texto.

Exercício 4 · Mini formulário de cadastro

Crie mini_formulario.py que faça pelo menos 3 perguntas diferentes — misturando texto e número — e no final mostre um resumo com todas as respostas usando f-string. Use int() ou float() em toda pergunta numérica.

nome = input("Nome completo: ") idade = int(input("Idade: ")) cidade = input("Cidade: ") altura = float(input("Altura (em metros, ex: 1.70): ")) print("----- RESUMO DO CADASTRO -----") print(f"Nome: {nome}") print(f"Idade: {idade} anos") print(f"Cidade: {cidade}") print(f"Altura: {altura} m")

Repare que altura usa float(), não int() — porque uma altura como 1,70 tem casas decimais. Se você usar int() nesse caso, o Python dá erro ao tentar converter um texto com vírgula/ponto para inteiro.
