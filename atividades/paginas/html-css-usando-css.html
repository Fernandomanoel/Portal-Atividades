1. O que é HTML?

HTML é a estrutura da página.

Ele cria títulos, textos e imagens.

Exemplo:

<h1>Olá!</h1> <p>Esta é minha página.</p>
  • <h1> → cria um título
  • <p> → cria um parágrafo (texto)

2. O que é CSS?

CSS é usado para decorar a página.

Ele muda:

  • cores 🎨
  • tamanho do texto 🔍
  • fundo da página 🖼️
  • tamanho das imagens 📷

Pense assim:

HTML = esqueleto da casa
CSS = pintura e decoração

3. Estrutura básica da página

Veja um exemplo completo:

<!DOCTYPE html> <html> <head> <title>Minha Página</title> <style> </style> </head> <body> <h1>Minha Página</h1> <p>Estou aprendendo programação!</p> </body> </html>

Agora vamos entender cada parte.

4. Explicando cada parte

<!DOCTYPE html>

Significa que estamos criando uma página HTML.

<html>

É onde toda a página começa.

<head>

Aqui ficam informações da página.

<title>Minha Página</title>

Esse é o nome que aparece na aba do navegador.

<style>

<style> </style>

Aqui é onde escrevemos o CSS.

É onde vamos mudar cores e estilos.

<body>

<body> </body>

Aqui fica tudo que aparece na tela.

Exemplo:

  • textos
  • títulos
  • imagens

5. Criando um título

<h1>Minha Página Colorida</h1>

h1 significa título grande.

6. Criando um texto

<p>Eu estou aprendendo CSS!</p>

p significa parágrafo (texto).

7. Colocando uma imagem

<img src="https://upload.wikimedia.org/wikipedia/commons/3/32/House_sparrow04.jpg" >

Explicação:

img = imagem
src = endereço da imagem

8. Agora vamos usar CSS

Dentro do <style> escrevemos assim:

h1{ color: red; }

Explicação:

  • h1 → estamos mudando o título
  • color → muda a cor
  • red → vermelho

9. Mudando a cor do fundo

body{ background-color: lightblue; }

Explicação:

  • body → toda a página
  • background-color → cor do fundo
  • lightblue → azul claro

10. Mudando o tamanho do texto

p{ font-size: 20px; }

Explicação:

  • p → parágrafo
  • font-size → tamanho da letra
  • 20px → tamanho

11. Mudando o tamanho da imagem

img{ width: 200px; }

Explicação:

  • img → imagem
  • width → largura
  • 200px → tamanho

13. Código completo

<!DOCTYPE html> <html> <head> <title>Minha Página</title> <style> body { background-color: lightblue; } h1 { color: red; } p { font-size: 20px; } img { width: 200px; } </style> </head> <body> <h1>Minha Página com CSS</h1> <p>Estou aprendendo CSS!</p> <img src="https://upload.wikimedia.org/wikipedia/commons/3/32/House_sparrow04.jpg"> </body> </html>
