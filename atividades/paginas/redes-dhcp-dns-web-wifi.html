  • 01 Switch 2960-24TT

Endereçamento dos servidores

Configure os servidores com IP fixo:

EquipamentosFunçãoEndereço IP
Server0DHCP Server192.168.1.1
Server1Web Server192.168.1.2
Server2DNS Server192.168.1.3

Máscara de rede para todos:

255.255.255.0

Gateway:

192.168.1.1

🛠️ Montagem física

  1. Passo 1

    Adicione os equipamentos:

    • 1 Switch 2960-24TT
    • 3 Servers
    • 3 PCs
    • 1 Laptop
    • 1 Access Point

  2. Passo 2

    Conecte todos os dispositivos ao switch utilizando cabo Copper Straight-Through.

  3. Passo 3

    Conecte o notebook ao Access Point utilizando conexão Wireless.

📡 Configuração do DHCP

  1. Passo 4

    No servidor DHCP (192.168.1.1):

    Acesse:

    Services → DHCP

    Ative o serviço:

    DHCP Service = ON

    Crie um pool com as configurações:

    CamposValor
    Pool NameREDE
    Default Gateway192.168.1.1
    DNS Server192.168.1.3
    Start IP Address192.168.1.10
    Subnet Mask255.255.255.0
    Maximum Users100

    Clique em:

    Add

🖥️ Configuração dos clientes

  1. Passo 5

    Nos computadores PC0, PC1, PC2 e Laptop:

    Acesse:

    Desktop → IP Configuration

    Selecione:

    DHCP

    Verifique se receberam IP automaticamente.

📶 Configuração do Access Point

  1. Passo 6

    Configure o Access Point:

    SSID:

    FGTI

    Segurança:

    WPA2-PSK

    Senha:

    FP2026UCM

  2. Passo 7

    No notebook:

    Conecte-se à rede Wi-Fi:

    FGTI

    Usando a senha:

    FP2026UCM

🌍 Configuração do DNS

  1. Passo 8

    No servidor DNS (192.168.1.3):

    Acesse:

    Services → DNS

    Ative:

    DNS Service = ON

    Adicione o registro:

    NomeEndereço
    www.fgti.com192.168.1.2

    Clique em:

    Add

🖥️ Configuração do servidor Web

  1. Passo 9

    No servidor Web (192.168.1.2):

    Acesse:

    Services → HTTP

    Ative:

    HTTP = ON

    Edite a página index.html com o seguinte conteúdo:

    <html> <head> <title>FGTI</title> </head> <body> <h1>Fundamentos de Redes</h1> <h2>Atividade de DHCP, DNS e HTTP</h2> <p>Servidor Web funcionando corretamente.</p> </body> </html>

✅ Testes

  1. Passo 10

    Teste:

    ping 192.168.1.1 ping 192.168.1.2 ping 192.168.1.3

    Abra o navegador:

    Desktop → Web Browser

    Digite:

    http://192.168.1.2

    A página deverá abrir.

  2. Passo 11

    Teste o DNS:

    Digite:

    http://www.fgti.com

    A mesma página deverá ser exibida.
