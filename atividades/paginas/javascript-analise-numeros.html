🎯 Objetivo

Você vai criar um programa que:

  1. Peça um número inicial
  2. Peça um número final
  3. Mostre:
    • Todos os números do intervalo
    • Quais são pares
    • Quais são ímpares
    • A soma total dos números
  4. No final, diga se a soma é maior que 100 ou não

🚀 Com isso você vai treinar

  • ✅ Variáveis
  • ✅ if / else
  • ✅ for
  • ✅ while
  • ✅ Funções
  • ✅ Operações matemáticas

🧩 Parte 2 – Criando variáveis e recebendo dados

let inicio = parseInt(prompt("Digite o número inicial:"));
  • let cria uma variável.
  • inicio guarda o valor digitado.
  • prompt() pede um valor ao usuário.
  • parseInt() converte o texto para número inteiro.
let fim = parseInt(prompt("Digite o número final:"));

Mesma lógica, mas agora guardando o número final.

let soma = 0;

Criamos uma variável chamada soma.
Ela começa com valor 0 porque vamos acumular valores nela.

🧩 Parte 3 – Usando FOR (laço de repetição)

for (let i = inicio; i <= fim; i++) {

Vamos entender isso com calma:

  • let i = inicio → começa pelo número inicial
  • i <= fim → continua enquanto i for menor ou igual ao final
  • i++ → aumenta 1 a cada repetição

Isso faz o programa repetir várias vezes automaticamente.

console.log("Número:", i);

Mostra cada número no console.

🧩 Parte 4 – Usando IF / ELSE

if (i % 2 === 0) {
  • % é o operador de resto da divisão.
  • Se o resto da divisão por 2 for 0 → número é par.
console.log("É par");

Se for par, mostra essa mensagem.

} else { console.log("É ímpar"); }

Se não for par, é ímpar.

🧩 Parte 5 – Somando os números

soma = soma + i;

A cada repetição, adicionamos o número atual à variável soma.

Exemplo:

  • soma começa em 0
  • depois vira 0 + 1
  • depois 1 + 2
  • depois 3 + 3
  • e assim por diante...

🧩 Parte 6 – Usando WHILE

Agora vamos usar um while só para treinar outro tipo de repetição.

let contador = inicio;

Criamos uma variável auxiliar.

while (contador <= fim) { contador++; }

Esse while só percorre os números novamente.
Ele repete enquanto a condição for verdadeira.

🧩 Parte 7 – Verificando a soma

if (soma > 100) { console.log("A soma é maior que 100"); } else { console.log("A soma é menor ou igual a 100"); }

Aqui usamos if novamente para comparar o valor final da soma.

🧩 Parte 8 – Mostrando resultado final

🚀 Código Completo

Agora tudo junto:

function analisarNumeros() { let inicio = parseInt(prompt("Digite o número inicial:")); let fim = parseInt(prompt("Digite o número final:")); let soma = 0; for (let i = inicio; i <= fim; i++) { console.log("Número:", i); if (i % 2 === 0) { console.log("É par"); } else { console.log("É ímpar"); } soma = soma + i; } let contador = inicio; while (contador <= fim) { contador++; } if (soma > 100) { console.log("A soma é maior que 100"); } else { console.log("A soma é menor ou igual a 100"); } console.log("Soma total:", soma); } analisarNumeros();
