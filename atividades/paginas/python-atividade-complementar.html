1️⃣ Atividade 1 — Soma de Números

Objetivo: Aprender print, input, variáveis, conversão de tipos e cálculo simples.

Passo 1 – Criar o arquivo

Crie um arquivo chamado:

atividade_python.py

Passo 2 – Mostrar uma mensagem na tela

print("Olá, seja bem-vindo ao Python!")

👉 Esse comando serve para mostrar mensagens na tela.

Passo 3 – Pedir o nome do usuário

nome = input("Digite seu nome: ")

👉 Aqui o programa:

  • Pede uma informação
  • Guarda o valor digitado na variável nome

Passo 4 – Pedir dois números e fazer a soma

numero1 = int(input("Digite o primeiro número: ")) numero2 = int(input("Digite o segundo número: ")) soma = numero1 + numero2

👉 O int() é usado para transformar o texto digitado em número.

Passo 5 – Mostrar o resultado final

print("Olá,", nome) print("A soma dos números é:", soma)

Código completo (para o aluno copiar e rodar)

print("Olá, seja bem-vindo ao Python!") nome = input("Digite seu nome: ") numero1 = int(input("Digite o primeiro número: ")) numero2 = int(input("Digite o segundo número: ")) soma = numero1 + numero2 print("Olá,", nome) print("A soma dos números é:", soma)

⭐ Desafio opcional (iniciante)

Peça para o aluno:

  • Trocar a soma por multiplicação
multiplicacao = numero1 * numero2 print("A multiplicação é:", multiplicacao)

2️⃣ Atividade 2 — Maior de Idade

🎯 Objetivo: Ensinar variáveis, input, conversão de tipos e estrutura condicional (if / else).

Passo 1 – Criar o arquivo

atividade_python_idade.py

Passo 2 – Pedir o nome do usuário

nome = input("Digite seu nome: ")

Passo 3 – Pedir a idade

idade = int(input("Digite sua idade: "))

👉 O int() transforma o valor digitado em número.

Passo 4 – Criar a condição

if idade >= 18: mensagem = "Você é maior de idade." else: mensagem = "Você é menor de idade."

👉 Aqui o programa toma uma decisão.

Passo 5 – Mostrar o resultado

print("Olá,", nome) print(mensagem)

✅ Código completo (para copiar e executar)

nome = input("Digite seu nome: ") idade = int(input("Digite sua idade: ")) if idade >= 18: mensagem = "Você é maior de idade." else: mensagem = "Você é menor de idade." print("Olá,", nome) print(mensagem)

  • Mude a idade mínima para 16 anos
  • Acrescente uma mensagem de boas-vindas personalizada
