Equipamentos

A topologia utilizada será:

  • Switch S1 - Cisco 2960
  • Switch S2 - Cisco 2960
  • PC-A
  • PC-B

Conexões

  • PC-A conectado ao Switch S1 na porta FastEthernet 0/6
  • PC-B conectado ao Switch S2 na porta FastEthernet 0/18
  • Switch S1 conectado ao Switch S2 pelas portas FastEthernet 0/1

Os cabos utilizados são

  • Cabo Copper Straight-Through para conectar computadores aos switches.
  • Cabo Copper Cross-Over para conectar os switches.

⚙️ Configuração do Switch S1

Acesse o Switch S1. Clique em: CLI

Digite os comandos. Entrar no modo privilegiado:

Enable

Entrar no modo de configuração:

configure terminal

Alterar o nome do switch:

hostname S1

Configurar a interface VLAN 1:

interface vlan 1

Adicionar endereço IP:

ip address 192.168.1.1 255.255.255.0

Ativar a interface:

no shutdown

Sair:

exit

Salvar:

copy running-config startup-config

⚙️ Configuração do Switch S2

Acesse o Switch S2. Clique em: CLI

Digite os comandos. Entrar no modo privilegiado:

Enable

Entrar no modo de configuração:

configure terminal

Alterar o nome do switch:

hostname S2

Configurar a interface VLAN 1:

interface vlan 1

Adicionar endereço IP:

Ativar a interface:

Sair:

Salvar:

🔎 Verificação da configuração

Para verificar se os switches receberam os endereços IP corretamente, utilizar o comando:

show ip interface brief

No Switch S1 deve aparecer:

VLAN1 192.168.1.1 up

No Switch S2:

VLAN1 192.168.1.2 up

✅ Teste de comunicação

Para testar a comunicação entre os computadores:

No PC-A: Acesse Desktop → Command Prompt. Digite:

ping 192.168.1.11

Se aparecer:

Reply from 192.168.1.11

significa que o PC-A conseguiu comunicar com o PC-B.

Teste dos switches

No PC-A, teste o Switch S1:

ping 192.168.1.1

No PC-B, teste o Switch S2:

ping 192.168.1.2

Se houver resposta, a configuração está correta.
