🗂️ Arquivos, Compactação e Segurança de Pastas

Windows 11 — Organização de Verdade

← Voltar para Windows 11

🎯 Objetivo Geral

Criar uma estrutura de pastas como em um projeto de verdade, compactar arquivos para economizar espaço e facilitar o envio, e aprender formas simples (e os limites) de proteger uma pasta de olhares curiosos.

1️⃣ Atividade 1: Estrutura de Pastas de um Projeto

Tarefa

  1. Crie uma pasta "Projeto Final" dentro de Documentos.
  2. Dentro dela, crie 3 subpastas: "Textos", "Imagens" e "Backup".
  3. Em "Textos", crie 2 arquivos .txt com conteúdos diferentes.
  4. Em "Imagens", salve pelo menos 1 captura de tela (Windows + Shift + S).

Objetivo: Organizar informação em hierarquia — do jeito que qualquer projeto real é organizado.

2️⃣ Atividade 2: Renomeação em Lote

Tarefa

  1. Dentro de "Textos", selecione os 2 arquivos ao mesmo tempo (clique no primeiro, segure Ctrl e clique no segundo).
  2. Pressione F2 e digite um nome, como "anotacao", e pressione Enter.
  3. Observe: o Explorador numera os arquivos automaticamente — "anotacao (1).txt", "anotacao (2).txt".

🏆 Desafio Extra

Crie mais 3 arquivos de texto vazios em "Textos" (total de 5), selecione todos e renomeie em lote de uma vez só.

Objetivo: Descobrir um atalho de produtividade real do Explorador de Arquivos.

3️⃣ Atividade 3: Compactando a Pasta Inteira

Tarefa

  1. Clique com o botão direito na pasta "Projeto Final" → Enviar para → Pasta compactada (zipada).
  2. Compare o tamanho do arquivo .zip gerado com o tamanho da pasta original (botão direito → Propriedades em cada um).
  3. Copie o .zip para dentro da subpasta "Backup".
  4. Clique com o botão direito no .zip → Extrair tudo, escolha outra pasta, e confirme que os arquivos saíram intactos.

Objetivo: Entender compactação como forma de economizar espaço e de enviar vários arquivos como um só.

4️⃣ Atividade 4: Compactação NTFS (Invisível)

Tarefa

  1. Clique com o botão direito na pasta "Textos" → Propriedades → Avançados.
  2. Marque "Compactar conteúdo para economizar espaço em disco" e confirme.
  3. Observe se o nome da pasta ou dos arquivos aparece em uma cor diferente (indicando compactação NTFS ativa).
  4. Ao final, desmarque a opção — deixe a pasta como estava.
⚠️ Essa compactação é diferente do ZIP: ela é "invisível" — os arquivos continuam abrindo normalmente, sem precisar extrair nada. Só ocupam menos espaço no disco.

5️⃣ Atividade 5: Ocultando uma Pasta

Tarefa

  1. Crie uma pasta chamada "Particular" dentro de "Projeto Final".
  2. Clique com o botão direito → Propriedades → marque o atributo "Oculto".
  3. Feche e reabra o Explorador de Arquivos — a pasta deve sumir da visualização.
  4. Na faixa de opções, ative Exibir → Mostrar → Itens ocultos para vê-la de novo, e depois desative essa exibição.

Objetivo: Perceber que "ocultar" é uma proteção simples contra olhares casuais — não é uma senha de verdade, qualquer um que saiba mostrar itens ocultos consegue ver.

6️⃣ Atividade 6: Verificando Permissões de uma Pasta

Tarefa

  1. Clique com o botão direito em "Projeto Final" → Propriedades → aba "Segurança".
  2. Veja a lista de "Nomes de grupo ou usuário" e clique em cada um para ver o que pode fazer (Leitura, Gravação, Controle total).
  3. Anote no seu arquivo de anotações quem tem permissão de "Controle total" nessa pasta.
⚠️ Não altere nada na aba Segurança. Mudar permissões por engano pode travar o acesso à própria pasta, até para você. Esta atividade é só de observação.
