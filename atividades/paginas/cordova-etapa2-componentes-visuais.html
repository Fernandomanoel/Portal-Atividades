🎯 O plano desta etapa

Na Etapa 1 você criou o projeto e colocou um cabeçalho e um cartão na tela. Agora vamos montar a tela inteira do "Minhas Missões": um campo pra digitar uma missão, um botão pra adicionar, um espaço pra lista aparecer, e um rodapé. Ainda não vamos programar nada em JavaScript — hoje é só montar as peças visuais, uma por uma, entendendo o que cada uma faz. Na Etapa 3 elas ganham vida.

🎨 As cores prontas do Ionic

Você já viu color="primary" na Etapa 1. O Ionic vem com um conjunto de cores prontas que você pode usar em quase qualquer componente:

primary secondary tertiary success warning danger medium dark

Vamos usar várias delas ao longo desta etapa.

🧩 Peça por peça

Para cada peça abaixo: leia a explicação, copie o código pro lugar certo dentro do <ion-content> do seu www/index.html (embaixo do cartão de boas-vindas que já está lá), salve e rode de novo pra ver o resultado antes de ir pra próxima.

1. Campo de texto — ion-input

Peça 1

É onde a usuária vai digitar o nome de uma missão nova.

html<ion-item> <ion-label position="floating">Nova missão</ion-label> <ion-input id="campo-missao" placeholder="Ex: Arrumar o quarto"></ion-input> </ion-item>

<ion-item> é uma "linha" — o Ionic usa ela como container padrão dentro de listas e formulários. <ion-label position="floating"> é aquele rótulo que começa dentro do campo e "flutua" pra cima quando você clica — repare o efeito quando testar. O id="campo-missao" é importante: é assim que o JavaScript vai encontrar esse campo na Etapa 3, então não troque esse nome.

2. Botão com ícone — ion-button + ion-icon

Peça 2

O botão que vai adicionar a missão na lista.

html<ion-button id="btn-adicionar" expand="block" color="success"> <ion-icon slot="start" name="add-circle"></ion-icon> Adicionar Missão </ion-button>

expand="block" faz o botão esticar e ocupar toda a largura disponível — muito comum em apps mobile. <ion-icon name="add-circle"> insere um ícone pronto da biblioteca Ionicons; o atributo slot="start" diz "coloque esse ícone antes do texto". Existem centenas de ícones prontos — o site ionic.io/ionicons tem a lista completa com o nome exato de cada um.

3. Espaço para a lista — ion-list

Peça 3

Por enquanto vazio — na Etapa 3 o JavaScript vai preencher ele com as missões digitadas.

html<ion-list id="lista-missoes"></ion-list>

Uma <ion-list> vazia não aparece com nada visível ainda — isso é esperado. É só uma "caixa" esperando ser preenchida por código.

4. Organizando em colunas — ion-grid

Peça 4 (opcional, mas útil)

Se você já usou display: flex em CSS, isso vai parecer familiar: o Ionic tem seu próprio sistema de colunas, pronto pra telas de celular.

html<ion-grid> <ion-row> <ion-col size="6"> <ion-button expand="block" color="tertiary">Fáceis</ion-button> </ion-col> <ion-col size="6"> <ion-button expand="block" color="danger">Difíceis</ion-button> </ion-col> </ion-row> </ion-grid>

<ion-grid> é a grade inteira, <ion-row> é uma fileira, e cada <ion-col size="6"> ocupa metade da largura (a grade do Ionic vai de 1 a 12 — size="6" é metade, size="4" seria um terço, e assim por diante). Esses dois botões não precisam funcionar de verdade agora — é só pra você ver como se organiza layout em colunas no Ionic.

5. Um rodapé fixo — ion-footer

Peça 5

Diferente do <ion-header>, o rodapé fica fora do <ion-content> — ele é irmão dele, não filho. Repare na indentação no código completo abaixo.

html<ion-footer> <ion-toolbar> <ion-title size="small">Feito por [seu nome aqui]</ion-title> </ion-toolbar> </ion-footer>

📄 Como fica o index.html completo até agora

Juntando tudo (cabeçalho da Etapa 1 + as peças novas), seu www/index.html deve ficar parecido com isto:

www/index.html<ion-app> <ion-header> <ion-toolbar color="primary"> <ion-title>Minhas Missões</ion-title> </ion-toolbar> </ion-header> <ion-content class="ion-padding"> <ion-card> <ion-card-header> <ion-card-title>Bem-vinda!</ion-card-title> </ion-card-header> <ion-card-content> Digite suas missões abaixo e não esqueça de completá-las! </ion-card-content> </ion-card> <ion-item> <ion-label position="floating">Nova missão</ion-label> <ion-input id="campo-missao" placeholder="Ex: Arrumar o quarto"></ion-input> </ion-item> <ion-button id="btn-adicionar" expand="block" color="success"> <ion-icon slot="start" name="add-circle"></ion-icon> Adicionar Missão </ion-button> <ion-list id="lista-missoes"></ion-list> </ion-content> <ion-footer> <ion-toolbar> <ion-title size="small">Feito por [seu nome aqui]</ion-title> </ion-toolbar> </ion-footer> </ion-app>

Salve, rode cordova run browser e confira: você já tem uma tela completa de app, com cabeçalho, cartão, campo de texto, botão colorido com ícone, uma lista (ainda vazia) e um rodapé. Falta só uma coisa: fazer o botão fazer alguma coisa quando clicado — é exatamente isso que vem na Etapa 3.

💾 Lembrete: salve e teste a cada peça nova, não espere terminar tudo pra rodar pela primeira vez. Se algo sumir ou ficar estranho, é mais fácil descobrir qual foi a última coisa que você mudou.

🎨 Deixe com a sua cara

No arquivo www/css/index.css, você pode estilizar por cima do visual do Ionic, exatamente como faria num site comum:

www/css/index.cssion-card { border-radius: 16px; } ion-title { font-family: 'Comic Sans MS', sans-serif; /* só um exemplo divertido */ }

Experimente mudar o border-radius do cartão, ou trocar a fonte do título. O CSS que você já conhece funciona perfeitamente em cima dos componentes do Ionic.

✅ Checklist da Etapa 2

  • Meu app tem um campo de texto (ion-input) com id="campo-missao";
  • Tenho um botão (ion-button) com ícone e id="btn-adicionar";
  • Tenho uma ion-list vazia com id="lista-missoes" esperando ser preenchida;
  • Tenho um rodapé (ion-footer) com meu nome;
  • Testei trocar pelo menos uma cor do Ionic (color="...") em algum componente;
  • Mexi um pouco no index.css pra deixar algo com a minha cara.
