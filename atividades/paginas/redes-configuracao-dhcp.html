🎯 Cenário

Uma empresa possui uma rede local e deseja automatizar a atribuição de endereços IP para seus computadores utilizando o serviço DHCP.

Você deverá criar um pool de endereços com as informações fornecidas e testar o funcionamento da distribuição automática de IP.

📋 Informações do pool DHCP

CampoValor
Pool NameREDE
Default Gateway192.168.1.1
DNS Server192.168.1.3
Start IP Address192.168.1.10
Subnet Mask255.255.255.0
Maximum Users100

🛠️ Desenvolvimento

  1. Passo 1

    Adicione os seguintes dispositivos ao projeto:

    • 01 Switch 2960
    • 01 Servidor
    • 03 Computadores

  2. Passo 2

    Conecte todos os equipamentos ao switch utilizando cabo Copper Straight-Through.

  3. Passo 3

    Configure o servidor com:

    ConfiguraçãoValor
    IP Address192.168.1.1
    Subnet Mask255.255.255.0

  4. Passo 4

    No servidor, acesse:

    Services → DHCP

    Ative o serviço DHCP.

  5. Passo 5

    Crie um novo Pool com as seguintes configurações:

    Pool Name: REDE Default Gateway: 192.168.1.1 DNS Server: 192.168.1.3 Start IP Address: 192.168.1.10 Subnet Mask: 255.255.255.0 Maximum Users: 100

    Após preencher os campos, clique em Add.

  6. Passo 6

    Nos computadores, acesse:

    Desktop → IP Configuration

    Selecione a opção:

    DHCP

  7. Passo 7

    Verifique os endereços IP recebidos pelos computadores.

    Os primeiros dispositivos deverão receber IPs semelhantes a:

    PC0 → 192.168.1.10 PC1 → 192.168.1.11 PC2 → 192.168.1.12
