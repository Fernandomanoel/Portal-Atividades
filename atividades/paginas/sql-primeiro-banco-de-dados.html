📋 Meu Primeiro Banco de Dados

Uma escola decidiu criar um pequeno banco de dados para armazenar informações sobre seus alunos. Para isso, será criada uma tabela chamada alunos, que guardará alguns dados importantes.

A tabela deve conter as seguintes informações:

  • id (do aluno)
  • nome (do aluno)
  • idade
  • cidade (onde mora)

Depois de criar a tabela, alguns registros de alunos deverão ser inseridos no banco de dados.

Com os dados cadastrados, responda às seguintes perguntas utilizando consultas SQL:

  1. Mostre todos os dados da tabela alunos.
  2. Mostre apenas o nome e a idade dos alunos.
  3. Mostre os alunos que moram em Manaus.
  4. Mostre os alunos que têm idade maior que 20 anos.
  5. Liste todos os alunos ordenados pela idade do maior para o menor.

Objetivo da atividade

Praticar comandos básicos de SQL como CREATE TABLE, INSERT INTO, SELECT, WHERE e ORDER BY.

1️⃣ Parte 1: Criar a tabela

Crie uma tabela chamada alunos com as seguintes colunas:

  • id (inteiro, chave primária)
  • nome (texto)
  • idade (inteiro)
  • cidade (texto)

Escreva o código abaixo:

CREATE TABLE alunos ( id INT PRIMARY KEY, nome VARCHAR(100), idade INT, cidade VARCHAR(100) );

2️⃣ Parte 2: Inserir dados

Insira alguns alunos na tabela:

INSERT INTO alunos (id, nome, idade, cidade) VALUES (1, 'Ana', 20, 'Manaus'), (2, 'Carlos', 22, 'São Paulo'), (3, 'Marina', 19, 'Rio de Janeiro'), (4, 'João', 21, 'Manaus');

3️⃣ Parte 3: Consultas básicas

Mostrar todos os alunos:

SELECT * FROM alunos;

Mostrar apenas nome e idade:

SELECT nome, idade FROM alunos;

Mostrar alunos que moram em Manaus:

SELECT * FROM alunos WHERE cidade = 'Manaus';

Mostrar alunos com idade maior que 20:

SELECT * FROM alunos WHERE idade > 20;

📖 Explicação dos comandos

1. CREATE TABLE

O que faz?

O comando CREATE TABLE serve para criar uma tabela dentro do banco de dados.

Exemplo:

CREATE TABLE alunos ( id INT PRIMARY KEY, nome VARCHAR(100), idade INT, cidade VARCHAR(100) );

Como funciona

  • CREATE TABLE alunos → cria uma tabela chamada alunos.
  • Dentro dos parênteses ficam as colunas da tabela.

Explicação das colunas:

ColunaTipoSignificado
IdINTNumero Inteiro e também o principal do banco de dados a Primary Key ou Chave Primária.
NomeVARCHAR(100)Cria um texto com até 100 caracteres
IdadeINTIdade sendo um número Inteiro
CidadeVARCHAR(100)Nome da Cidade com até 100 caracteres

2. INSERT INTO

O que faz

O comando INSERT INTO serve para inserir dados dentro da tabela.

Exemplo:

INSERT INTO alunos (id, nome, idade, cidade) VALUES (1, 'Ana', 20, 'Manaus'), (2, 'Carlos', 22, 'São Paulo');

Como funciona

  • INSERT INTO alunos → diz em qual tabela vamos inserir dados.
  • (id, nome, idade, cidade) → indica as colunas que receberão valores.
  • VALUES → indica os valores que serão inseridos.

Cada linha representa um registro (um aluno).

3. SELECT

O que faz

O comando SELECT é usado para consultar dados da tabela.

Exemplo

SELECT * FROM alunos;

Como funciona

  • SELECT → seleciona dados.
  • * → significa todas as colunas.
  • FROM alunos → indica de qual tabela os dados serão buscados.

Resultado: mostra todas as informações dos alunos.

4. SELECT com colunas específicas

Exemplo:

SELECT nome, idade FROM alunos;

Como funciona

  • SELECT nome, idade → mostra apenas essas duas colunas.
  • FROM alunos → busca os dados na tabela alunos.

Resultado: mostra apenas nome e idade, não todas as colunas.

5. WHERE

O que faz

O comando WHERE serve para filtrar dados, ou seja, mostrar apenas registros que atendem uma condição.

Exemplo:

SELECT * FROM alunos WHERE idade > 20;

Como funciona

  • WHERE cidade = 'Manaus' → mostra apenas alunos que moram em Manaus.

Outro exemplo:

SELECT * FROM alunos WHERE idade > 20;

Operadores comuns:

OperadoresSignificados
=IGUAL
>MAIOR
<MENOR
>=MAIOR OU IGUAL
=<MENOR OU IGUAL

6. ORDER BY

O que faz

O comando ORDER BY serve para ordenar os resultados.

Exemplo

SELECT * FROM alunos ORDER BY idade DESC;

Como funciona

  • ORDER BY idade → ordena pela coluna idade.
  • DESC → do maior para o menor.

Tipos de ordenação:

ComandoResultado
ORDER BY idade ASCMaior > Maior
ORDER BY idade DESCMaior > Menor
