🎨 Estilizando uma Página do Zero

Você recebe uma página HTML sem nenhum estilo — sua missão é transformá-la com CSS, um passo de cada vez

Atividade prática — leve o tempo que precisar
← Voltar para Html e CSS

🎯 Como funciona esta atividade

É assim que se trabalha de verdade: primeiro alguém monta o HTML (a estrutura, o conteúdo, o "esqueleto" da página) e só depois entra o CSS (as cores, os espaçamentos, o layout — a "roupa" da página).

Abaixo tem uma página HTML pronta e completa, mas sem nenhum estilo — hoje ela é só texto puro, sem cor, sem organização visual. Seu trabalho é copiar esse HTML, criar o CSS do zero e ir estilizando ela seção por seção, seguindo os passos. No final, sua página vai ter cabeçalho colorido, cards organizados em grade e efeitos ao passar o mouse — tudo isso só com CSS, sem tocar no HTML.

📂 Antes de começar

Crie uma pasta pra essa atividade com dois arquivos:

  • index.html — cole o código HTML da seção abaixo;
  • style.css — comece vazio; é aqui que você vai escrever cada passo.

No index.html, dentro do <head>, já existe a linha que liga os dois arquivos: <link rel="stylesheet" href="style.css">. Basta salvar os dois na mesma pasta.

📄 O arquivo HTML de partida (copie exatamente assim)

Repare: é só estrutura. Nenhuma tag <style>, nenhum atributo de cor, nada. Abra esse arquivo no navegador agora, antes de mexer em qualquer CSS — vai aparecer tudo em preto e branco, empilhado. É esse visual "cru" que você vai transformar.

index.html<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Meu Perfil</title> <link rel="stylesheet" href="style.css"> </head> <body> <header class="topo"> <h1>Oi, eu sou a(o) SeuNome</h1> <nav class="menu"> <a href="#sobre">Sobre</a> <a href="#habilidades">Habilidades</a> <a href="#contato">Contato</a> </nav> </header> <section id="sobre" class="secao"> <h2>Sobre mim</h2> <p>Estou aprendendo HTML e CSS na Microlins. Este é um perfil de treino: todo o conteúdo já está pronto, só falta o estilo.</p> </section> <section id="habilidades" class="secao"> <h2>Habilidades</h2> <div class="grade-habilidades"> <div class="card"> <h3>HTML</h3> <p>Estrutura páginas com tags semânticas.</p> </div> <div class="card"> <h3>CSS</h3> <p>Estiliza cores, espaçamentos e layout.</p> </div> <div class="card"> <h3>Git</h3> <p>Salva o progresso dos projetos no repositório.</p> </div> </div> </section> <footer id="contato" class="rodape"> <p>Quer falar comigo? <a href="#">Envie um e-mail</a></p> </footer> </body> </html>
Depois de dominar os passos abaixo: troque "SeuNome" pelo seu nome, mude os textos e os cartões de habilidade para falar de você. A ideia é primeiro aprender a estilizar seguindo o roteiro, depois deixar a página com a sua cara.

🧩 Agora, passo a passo: escrevendo o CSS

Cada passo abaixo é um pedaço que você adiciona no style.css. Salve e recarregue o navegador depois de cada um — assim você vê a página mudando aos poucos, e entende exatamente o que cada regra fez.

1

Reset e fonte da página inteira

Toda folha de CSS começa "zerando" as margens padrão do navegador e escolhendo a fonte. É a base de tudo o que vem depois.

style.css/* zera margem/padding padrão e deixa o box-sizing intuitivo */ * { margin: 0; padding: 0; box-sizing: border-box; } body { font-family: 'Segoe UI', Arial, sans-serif; color: #333; line-height: 1.6; }
AntesFonte serifada padrão do navegador, texto colado nas bordas.
Depois deste passoFonte mais limpa, mas ainda sem cor nem organização — é só a base.
2

Estilizando o cabeçalho (header)

Vamos dar cor de fundo ao <header class="topo"> e organizar o título e o menu lado a lado com Flexbox.

style.css.topo { background: linear-gradient(135deg, #ff4da6, #c2367d); color: #fff; padding: 30px 40px; display: flex; flex-wrap: wrap; justify-content: space-between; align-items: center; gap: 16px; } .topo h1 { font-size: 1.6em; } .menu { display: flex; gap: 22px; } .menu a { color: #fff; text-decoration: none; font-weight: 600; }

O segredo é o display: flex no .topo: ele coloca o <h1> e o <nav> lado a lado automaticamente, e o justify-content: space-between empurra um pra cada ponta.

3

Espaçamento e título das seções

Agora damos um "respiro" (padding) para cada <section class="secao"> e destacamos os títulos <h2>.

style.css.secao { padding: 50px 40px; max-width: 1000px; margin: 0 auto; } .secao h2 { color: #c2367d; font-size: 1.8em; margin-bottom: 16px; border-bottom: 3px solid #ff4da6; padding-bottom: 8px; display: inline-block; } .secao p { font-size: 1.05em; color: #555; }

padding empurra o conteúdo pra dentro da caixa (o "recheio"); margin empurra a caixa inteira pra longe de outras coisas (o "espaço ao redor"). São as duas peças do box model — a base de todo layout em CSS.

4

Os cards de habilidade em grade (Flexbox de novo)

Os três <div class="card"> hoje estão empilhados um embaixo do outro. Vamos colocá-los lado a lado, com um visual de "cartão".

style.css.grade-habilidades { display: flex; flex-wrap: wrap; gap: 20px; margin-top: 20px; } .card { flex: 1 1 200px; background: #fdf1f8; border: 2px solid #ffd0e8; border-radius: 10px; padding: 22px; } .card h3 { color: #c2367d; margin-bottom: 8px; }

flex: 1 1 200px quer dizer: cada card tenta ter pelo menos 200px, mas cresce pra dividir o espaço igualmente com os outros. Com 3 cards eles ficam lado a lado; se a tela for estreita, o flex-wrap: wrap deixa eles quebrarem pra próxima linha.

5

Efeito ao passar o mouse (hover)

Um toque de interatividade: o card "sobe" e ganha sombra quando o mouse passa por cima. Isso é puro CSS, sem nenhuma linha de JavaScript.

style.css.card { /* ...as regras do passo anterior continuam aqui... */ transition: transform 0.2s, box-shadow 0.2s; } .card:hover { transform: translateY(-6px); box-shadow: 0 10px 24px rgba(255,77,166,0.25); } .menu a:hover { text-decoration: underline; }

transition é o que faz a mudança ser suave em vez de instantânea — sem ele, o card "pularia" direto para a posição nova. :hover é um pseudo-seletor: só vale enquanto o mouse está em cima do elemento.

6

Rodapé

Por último, um estilo simples para o <footer class="rodape">.

style.css.rodape { background: #2b2b2b; color: #eee; text-align: center; padding: 26px; } .rodape a { color: #ff8ac4; font-weight: 700; }
7

Deixando responsivo (funcionar bem no celular)

No final do style.css, adicione um bloco @media — ele só vale quando a tela é estreita, e ajusta o que precisa mudar.

style.css (no final do arquivo)@media (max-width: 600px) { .topo { flex-direction: column; text-align: center; } .secao { padding: 36px 22px; } .card { flex: 1 1 100%; } }

Teste apertando F12 no navegador e ativando o modo de simulação de celular (ícone de tablet/celular) — arraste a largura e veja o cabeçalho empilhar e os cards ficarem um por linha.

Pronto! Com esses 7 passos, a mesma página HTML que começou em preto e branco agora tem cabeçalho colorido, menu organizado, cards em grade com efeito hover, e funciona bem no celular — tudo isso mudando só o CSS, sem tocar numa linha do HTML. É exatamente essa separação (estrutura de um lado, estilo do outro) que torna sites fáceis de manter.

🚀 Agora vá além (desafios opcionais)

Depois de reproduzir os 7 passos, tente sozinho, sem roteiro:

  • Troque as cores rosa por uma paleta sua — mude só os valores de cor, mantendo a estrutura;
  • Adicione um 4º card de habilidade;
  • Faça o <h1> do cabeçalho ganhar uma sombra de texto (text-shadow);
  • Troque a fonte por outra (pesquise "Google Fonts" para importar uma fonte diferente);
  • Adicione uma borda arredondada bem grande (border-radius) nos cards para um visual mais "bolha".

Não existe resposta errada aqui — o objetivo é você ganhar confiança para escrever CSS sem depender do roteiro.

✅ Checklist antes de considerar concluído

  • O index.html não foi alterado — só o style.css foi escrito;
  • O cabeçalho tem cor de fundo e o menu fica ao lado do título;
  • Os 3 cards de habilidade aparecem lado a lado (em tela larga) e um por linha no celular;
  • Passar o mouse em cima de um card produz um efeito visual;
  • A página não quebra (sem rolagem horizontal estranha) numa tela de celular simulada;
  • Pelo menos um dos desafios opcionais foi tentado.
