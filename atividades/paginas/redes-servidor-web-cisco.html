Equipamentos

Adicione:

  • 1 PC
  • 1 Switch 2960
  • 1 Server

Conecte os dispositivos utilizando o Copper Straight Through.

PC0 → SW1 SERVER0 → SW1

🖥️ Configuração do PC

Clique em:

PC0 → Desktop → IP Configuration

Configure:

IP Address: 192.168.1.10 Subnet Mask: 255.255.255.0

🗄️ Configuração do servidor

Clique em:

SERVER0 → Desktop → IP Configuration

Configure:

IP Address: 192.168.1.100 Subnet Mask: 255.255.255.0

✅ Teste de conectividade

No PC:

Desktop → Command Prompt

Digite:

ping 192.168.1.100

📝 Criando o site

Clique em:

SERVER0 → Services → HTTP

Ative:

HTTP = On

Clique em: index.html

Apague o conteúdo existente.

Coloque o código abaixo:

<div class="card"> <h2>Bem-vindo</h2> <p>Este servidor foi configurado utilizando o Cisco Packet Tracer.</p> </div> <div class="card"> <h2>Conteúdo da Disciplina</h2> <ul> <li>Endereçamento IPv4</li> <li>Switches e VLANs</li> <li>Roteamento</li> <li>DHCP</li> <li>DNS</li> <li>Servidores Web</li> </ul> </div> <div class="card"> <h2>Atividade Atual</h2> <p>Configuração de VLANs e Troncos 802.1Q.</p> </div>

Clique em:

Save

🔍 Acessando o site

No PC:

Desktop → Web Browser

Digite:

http://192.168.1.100 ou 192.168.1.100

Clique em:

Go

🌍 Usar o DNS no Cisco Packet Tracer

Em vez de acessar:

http://192.168.1.100

Você pode acessar:

http://www.cisco.site

Para isso:

  1. Use o Server para DNS.
  2. Configure um IP para ele (ex.: 192.168.1.100).
  3. Vá em Services → DNS.
  4. Ative DNS = On.
  5. Adicione um registro:
NomeEndereço
www.cisco.site192.168.1.100

Nos PCs, configure o DNS:

DNS Server: 192.168.1.200
⚠️ O PDF original indica 192.168.1.200 como o DNS Server configurado nos PCs, mesmo o servidor DNS tendo sido definido com o IP 192.168.1.100 no passo anterior. Mantivemos exatamente o valor do material original — vale conferir com o instrutor qual IP está correto antes de aplicar na prática.

Agora o navegador do Packet Tracer poderá abrir:

http://www.cisco.site
