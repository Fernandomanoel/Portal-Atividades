# Ícones dos cursos

Coloque aqui uma imagem `.png` para cada curso, nomeada com o "slug" do
nome do curso: minúsculo, sem acento, espaços e outros caracteres viram
hífen.

Exemplos:
- Curso "Excel Avançado I" → `excel-avancado-i.png`
- Curso "C#" → `c.png`
- Curso "Windows 11" → `windows-11.png`

Se não tiver certeza do slug de um curso, abra o site, clique com o
botão direito no ícone (a letra dentro do quadrado colorido) e veja o
"Inspecionar elemento" — o `src` que ele tentou carregar mostra o nome
exato do arquivo esperado.

Não precisa editar nenhum código: assim que o arquivo `.png` estiver
nesta pasta com o nome certo, ele substitui a letra automaticamente na
próxima vez que a página for carregada (tanto na aba Atividades quanto
na aba Provas).
