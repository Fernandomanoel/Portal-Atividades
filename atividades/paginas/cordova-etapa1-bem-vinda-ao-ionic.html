🎯 O que você já sabe (e o que muda agora)

Você já construiu páginas com HTML, deixou elas bonitas com CSS e já brincou um pouco com JavaScript. Ótimo — porque tudo isso continua valendo. A diferença é que, a partir de hoje, o que você constrói não vai ficar só dentro de um navegador de computador: vai virar um aplicativo de verdade, do tipo que você instala e abre no celular, com um ícone na tela e tudo.

Pra isso, vamos usar duas ferramentas novas:

🏠 Pensa numa casa pronta para mudar de cidade

Ionic é como os móveis já prontos no tamanho certo — botões, menus, cartões e telas que já nascem com a cara de aplicativo de celular, prontos pra você usar, sem ter que desenhar cada um do zero.

Cordova é o caminhão de mudança: ele pega toda a "casa" que você construiu com HTML/CSS/JS e leva ela pra dentro do celular, traduzindo tudo pra linguagem que o processador do aparelho entende.

Ou seja: você continua escrevendo HTML, CSS e JavaScript — só que agora com peças prontas de aplicativo (Ionic) e um jeito de colocar tudo isso rodando de verdade num celular (Cordova).

🗺️ O que vamos construir nessas 5 etapas

Ao longo das próximas aulas você vai construir, peça por peça, um aplicativo chamado Minhas Missões — uma lista de tarefas (ou o que você quiser: filmes pra assistir, livros pra ler, ideias de desenho) que vive dentro do celular e lembra do que você digitou mesmo depois de fechar o app. No final, ele vai rodar de verdade num celular simulado no computador.

  • Etapa 1 (agora): criar o projeto e entender as peças do Ionic;
  • Etapa 2: montar a tela toda com componentes visuais do Ionic;
  • Etapa 3: dar vida à tela com JavaScript — cliques, listas que aparecem na hora;
  • Etapa 4: fazer o app "lembrar" das coisas e testar num celular virtual;
  • Etapa 5: projeto final, com a sua cara.

💻 Criando seu primeiro projeto

O computador já tem tudo instalado (o Node.js, o Cordova e o Ionic) — você não precisa instalar nada, só usar. Abra o terminal na pasta onde quer guardar seus projetos e digite, um comando de cada vez:

  1. Criar o projeto. Isso cria uma pasta nova chamada meu-app com tudo que um app precisa pra existir.
    terminalcordova create meu-app com.escola.meuapp "Minhas Missões"

    Esse comando tem 3 partes: o nome da pasta (meu-app), um "identificador único" do app (com.escola.meuapp — todo app precisa de um, como um CPF) e o nome que vai aparecer embaixo do ícone no celular ("Minhas Missões").

  2. Entrar na pasta do projeto.
    terminalcd meu-app
  3. Preparar a pré-visualização no navegador. Antes de testar num celular de verdade, é mais rápido ver o app rodando direto no navegador do computador.
    terminalcordova platform add browser
  4. Rodar o app!
    terminalcordova run browser

    Uma aba do navegador vai abrir sozinha mostrando uma tela simples de boas-vindas do Cordova. Parabéns — você acabou de criar e rodar seu primeiro projeto de aplicativo!

💾 Ciclo curto: a partir de agora, sempre que você mudar um arquivo, salve com Ctrl + S e rode cordova run browser de novo (ou só recarregue a aba) pra ver a mudança. Não escreva 50 linhas antes de testar — teste a cada pedacinho.

📂 Conhecendo a pasta do seu app

Abra a pasta meu-app no seu editor de código. Repare que dentro dela existe uma pasta chamada www — é ali, e só ali, que mora o app de verdade. O resto da pasta é configuração que o Cordova usa por trás dos panos; você não precisa mexer nela.

o que importa, dentro de www/ meu-app/ └── www/ ├── index.html # a tela do seu app — o que aparece na tela ├── css/ │ └── index.css # o estilo visual do app └── js/ └── index.js # a lógica — o que acontece quando você toca em algo

Abra o www/index.html. Repare que seu mentor já deixou, dentro do <head>, duas linhas que carregam a biblioteca do Ionic — é isso que faz as tags especiais como <ion-button> funcionarem daqui pra frente. Você não precisa mexer nelas, só saber que estão ali.

🧩 Seu primeiro componente Ionic

Agora vamos trocar o conteúdo de dentro do <body> do index.html pelas primeiras peças do Ionic: um cabeçalho e um cartão de boas-vindas.

Copie isto dentro do <body>

www/index.html<ion-app> <!-- Cabeçalho do app: aparece fixo no topo, igual em apps de verdade --> <ion-header> <ion-toolbar color="primary"> <ion-title>Minhas Missões</ion-title> </ion-toolbar> </ion-header> <!-- Conteúdo principal da tela --> <ion-content class="ion-padding"> <ion-card> <ion-card-header> <ion-card-title>Bem-vinda!</ion-card-title> </ion-card-header> <ion-card-content> Este é o meu primeiro aplicativo de celular, criado por mim! </ion-card-content> </ion-card> </ion-content> </ion-app>

Salve o arquivo, rode cordova run browser de novo (ou recarregue a aba) e veja: apareceu uma barra azul no topo com o título, e um cartão branco com cantos arredondados logo abaixo. Sem escrever uma linha de CSS, já parece um app de verdade — esse é o trabalho que o Ionic faz por você.

O que cada tag nova faz

  • <ion-app> — envolve o app inteiro, é tipo o <body> de um app Ionic;
  • <ion-header> / <ion-toolbar> — a barra fixa do topo; o atributo color="primary" usa a cor principal do tema;
  • <ion-title> — o texto que aparece na barra;
  • <ion-content class="ion-padding"> — a área rolável onde fica o conteúdo; ion-padding dá um respiro nas bordas, pra nada colar na tela;
  • <ion-card> / <ion-card-header> / <ion-card-title> / <ion-card-content> — um "cartão" com título e texto dentro, o jeito Ionic de destacar um bloco de conteúdo.

🕵️ Modo detetive: o Console do navegador

Vez ou outra o app vai "quebrar" — a tela fica em branco, ou algo não aparece do jeito esperado. Isso é normal, acontece com programadores profissionais o tempo todo. O segredo é saber onde procurar a pista.

🔍 Como investigar um erro

  1. Aperte F12 no navegador (ou clique com o botão direito na página → Inspecionar);
  2. Clique na aba Console;
  3. Se algo deu errado, vai aparecer uma linha em vermelho explicando o que houve — geralmente com o nome do arquivo e o número da linha do problema;
  4. Leia a mensagem como uma pista de investigação: ela quase sempre diz exatamente o que está errado (uma tag não fechada, um nome escrito diferente em dois lugares, etc.).

Você vai usar o Console em toda etapa daqui pra frente — vale deixar o F12 aberto sempre que estiver codando.

⏱️ Hora da pausa: a cada bloco de uns 50 minutos codando, vale 10 minutos longe da tela — esticar as pernas, beber água. Até programador profissional trabalha assim.

🎨 Brinque um pouco antes de continuar

Antes de ir pra próxima etapa, tente sozinha:

  • Trocar o texto do <ion-title> por outro nome de app;
  • Trocar color="primary" por color="danger", color="success" ou color="warning" na <ion-toolbar> e ver a barra mudar de cor — o Ionic já vem com essas cores prontas;
  • Duplicar o <ion-card> inteiro e escrever um segundo cartão com outro texto.

✅ Checklist da Etapa 1

  • Criei o projeto com cordova create e consegui rodar com cordova run browser;
  • Sei onde fica a pasta www/ e entendo que é lá que meu app mora;
  • Meu app mostra um cabeçalho (ion-header) com título e um cartão (ion-card) de boas-vindas;
  • Já abri o Console (F12) pelo menos uma vez, só pra conhecer;
  • Testei trocar a cor da barra e o texto do título por conta própria.
