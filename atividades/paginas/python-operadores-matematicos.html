➗ O que são operadores matemáticos?

Operadores matemáticos são símbolos usados para realizar cálculos, como soma, subtração, multiplicação e divisão — exatamente como na matemática que você já conhece, só que escritos do jeito que o Python entende.

OperadorSignificadoExemploResultado
+Soma10 + 515
-Subtração10 - 55
*Multiplicação10 * 550
/Divisão (real, com decimais)10 / 52.0
%Resto da divisão10 % 31

Vamos ver cada um em código, um de cada vez.

Soma (+)

exemplonum1 = 10 num2 = 5 soma = num1 + num2 print("Soma:", soma) # Soma: 15

Subtração (-)

exemplonum1 = 10 num2 = 5 subtracao = num1 - num2 print("Subtração:", subtracao) # Subtração: 5

Multiplicação (*)

exemplonum1 = 10 num2 = 5 multiplicacao = num1 * num2 print("Multiplicação:", multiplicacao) # Multiplicação: 50

Resto da divisão (%)

O operador % (chamado de "módulo") mostra o que sobra de uma divisão, não o resultado da divisão em si. É muito usado, por exemplo, para descobrir se um número é par (resto da divisão por 2 igual a zero).

exemplonum1 = 10 num2 = 3 resto = num1 % num2 print("Resto da divisão:", resto) # Resto da divisão: 1 (pois 10 ÷ 3 = 3, e sobra 1)

➗ / vs // — a divisão tem dois modos em Python

Aqui vai um detalhe que muita gente não vê logo de cara: o Python tem dois operadores de divisão, e eles se comportam de jeitos bem diferentes.

/ — divisão real

Faz a divisão exata, com casas decimais, igual você faria numa calculadora.

10 / 3 = 3.333333...

// — divisão inteira

Faz a divisão e descarta a parte decimal, devolvendo só a parte inteira.

10 // 3 = 3

comparando / e //num1 = 10 num2 = 3 print("Divisão real:", num1 / num2) # Divisão real: 3.3333333333333335 print("Divisão inteira:", num1 // num2) # Divisão inteira: 3

💡 Quando usar cada uma?

  • Use / quando o resultado pode ter casas decimais — por exemplo, dividir uma conta de restaurante entre amigos;
  • Use // quando você só quer a parte inteira — por exemplo, "quantas caixas de 6 ovos eu preciso comprar para ter pelo menos 20 ovos" (aí você combinaria com % para saber quantos ovos sobram).

⚖️ Operadores de comparação

Além de calcular, o Python também compara valores. Um operador de comparação sempre devolve um destes dois valores especiais: True (verdadeiro) ou False (falso) — esse tipo de dado se chama bool (booleano), e é a base de toda decisão que um programa toma (o famoso if, que você vai estudar mais à frente).

OperadorSignificadoExemploResultado
==Igual a5 == 5True
!=Diferente de5 != 3True
>Maior que7 > 10False
<Menor que7 < 10True
>=Maior ou igual a10 >= 10True
<=Menor ou igual a9 <= 8False
exemploidade = 17 print(idade == 18) # False — 17 não é igual a 18 print(idade != 18) # True — 17 é diferente de 18 print(idade >= 18) # False — 17 não é maior nem igual a 18 print(idade < 18) # True — 17 é menor que 18
  • == (dois sinais de igual) compara se dois valores são iguais — nunca confunda com =, que serve para guardar um valor numa variável;
  • o resultado de uma comparação nunca é um número — é sempre True ou False;
  • essas comparações são exatamente o que, mais pra frente, você vai colocar dentro de um if para o programa tomar decisões sozinho.
Erro clássico de iniciante: escrever if idade = 18: em vez de if idade == 18:. Um sinal de igual guarda valor, dois sinais de igual comparam valor — são coisas completamente diferentes.

✅ Exercícios práticos

Exercício 1 · Soma de dois números

Peça dois números ao usuário (use input() convertendo com int()) e mostre a soma.

num1 = int(input("Digite o primeiro número: ")) num2 = int(input("Digite o segundo número: ")) soma = num1 + num2 print(f"A soma é {soma}")
Exercício 2 · Par ou ímpar

Peça um número ao usuário e mostre o resultado de numero % 2. Depois responda no comentário do próprio código: quando esse resultado é 0, o número é par ou ímpar?

numero = int(input("Digite um número: ")) resto = numero % 2 print(f"O resto da divisão de {numero} por 2 é {resto}") # Se o resto for 0, o número é par. Se for 1, é ímpar.
Exercício 3 · Calculadora simples completa

Crie um programa que peça dois números ao usuário e mostre todas as operações aprendidas: soma, subtração, multiplicação, divisão real, divisão inteira e resto — e ainda diga se o primeiro número é maior, menor ou igual ao segundo, usando operadores de comparação.

num1 = float(input("Digite o primeiro número: ")) num2 = float(input("Digite o segundo número: ")) print("----- RESULTADOS -----") print(f"Soma: {num1 + num2}") print(f"Subtração: {num1 - num2}") print(f"Multiplicação: {num1 * num2}") print(f"Divisão real: {num1 / num2}") print(f"Divisão inteira: {num1 // num2}") print(f"Resto da divisão: {num1 % num2}") print("----- COMPARAÇÕES -----") print(f"{num1} == {num2}? ", num1 == num2) print(f"{num1} > {num2}? ", num1 > num2) print(f"{num1} < {num2}? ", num1 < num2)

Usamos float() em vez de int() aqui de propósito — assim a calculadora funciona também com números decimais, como 7.5 ou 2.25, deixando o programa mais completo.
