🎯 Objetivo

Aprender a receber dados digitados pelo usuário usando o comando input().

📥 O que é o input()?

O input() é usado quando o programa faz uma pergunta e espera o usuário digitar uma resposta no teclado.

Tudo que o usuário digita com input() entra como texto (string).

Exemplo:

nome = input("Digite seu nome: ")

Preparando o arquivo no Visual Studio Code

  1. Abra o Visual Studio Code
  2. Clique em Arquivo > Novo Arquivo
  3. Salve como: entrada_dados.py

Primeiro programa com input()

Digite o código abaixo:

nome = input("Digite seu nome: ") print("Olá,", nome)

Executando

  • Clique com o botão direito no arquivo
  • Escolha Run Python File in Terminal
  • Digite seu nome no terminal e pressione Enter

🔢 input() com números

⚠️ Importante

O input() sempre recebe texto.

Para usar números, precisamos converter:

  • int() → números inteiros
  • float() → números com vírgula

Exemplo:

idade = int(input("Digite sua idade: ")) print("Você tem", idade, "anos")

Comentários no código

✅ Exercícios Práticos

Exercício 1 – Nome do usuário

Crie um programa que:

  1. Pergunte o nome do usuário
  2. Mostre a mensagem: Bem-vindo, [nome]!

Exemplo de solução:

nome = input("Digite seu nome: ") print("Bem-vindo,", nome)

Exercício 2 – Idade

Crie um programa que:

  1. Pergunte a idade do usuário
  2. Mostre quantos anos ele tem

Exemplo de solução:

idade = int(input("Digite sua idade: ")) print("Você tem", idade, "anos")
