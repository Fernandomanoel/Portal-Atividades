1️⃣ O que é Banco de Dados

Banco de dados é um local onde armazenamos informações organizadas.

Exemplo de informações armazenadas:

  • cadastro de alunos
  • cadastro de produtos
  • cadastro de clientes
  • vendas de uma loja

Esses dados ficam organizados em tabelas.

Exemplo de tabela

2️⃣ O que é SQL

SQL significa:

Structured Query Language

É a linguagem usada para consultar e manipular bancos de dados.

Com SQL podemos:

  • criar tabelas
  • inserir dados
  • consultar dados
  • atualizar dados
  • excluir dados

3️⃣ Criando uma tabela

Para criar uma tabela usamos o comando CREATE TABLE.

Exemplo:

CREATE TABLE alunos ( id INT, nome VARCHAR(50), idade INT );

4️⃣ Inserindo dados na tabela

Para inserir dados usamos INSERT INTO.

Exemplo:

INSERT INTO alunos VALUES (1,'Ana',20), (2,'Carlos',22), (3,'Maria',19);

Esse comando adiciona registros na tabela.

5️⃣ Consultando dados

Para visualizar dados usamos SELECT.

Exemplo:

SELECT * FROM alunos;

Explicação:

6️⃣ Filtrando informações

Podemos filtrar dados usando WHERE.

Exemplo:

SELECT * FROM alunos WHERE idade > 20;

Esse comando mostra apenas alunos com idade maior que 20.

7️⃣ Ordenando dados

Para organizar os dados usamos ORDER BY.

Exemplo:

SELECT * FROM alunos ORDER BY nome;

Esse comando organiza os alunos em ordem alfabética.

8️⃣ Atualizando dados

Para atualizar informações usamos UPDATE.

Exemplo:

UPDATE alunos SET idade = 21 WHERE nome = 'Ana';

9️⃣ Deletando dados

Para apagar dados usamos DELETE.

Exemplo:

DELETE FROM alunos WHERE id = 3;
