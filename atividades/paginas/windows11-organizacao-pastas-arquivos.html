📁 Organização de Pastas e Arquivos

Windows 11

← Voltar para Windows 11

🎯 Objetivo

Aprender a criar pastas, organizar documentos, editar arquivos e salvar uma imagem (print) no formato .bmp.

1️⃣ Parte 1 — Criar Pastas

  1. Na Área de Trabalho, clique com o botão direito do mouse.
  2. Clique em Novo → Pasta.
  3. Dê o nome da pasta principal:
    Atividade Windows
  4. Abra essa pasta e crie 3 subpastas com os nomes:
    • Textos
    • Imagens
    • Print

2️⃣ Parte 2 — Criar e Escrever Arquivos

  1. Entre na pasta Textos.
  2. Clique com o botão direito → Novo → Documento de Texto.
  3. Nomeie o arquivo como:
    texto1.txt
  4. Abra o arquivo e escreva um pequeno texto, por exemplo:

    Esta é uma atividade de Windows.
    Estou aprendendo a criar pastas e organizar arquivos.

  5. Clique em Arquivo → Salvar e feche.

3️⃣ Parte 3 — Organização

Confirme se:

  • O arquivo texto1.txt está dentro da pasta Textos.
  • As pastas estão organizadas dentro de Atividade Windows.

4️⃣ Parte 4 — Tirar Print da Tela

  1. Com a pasta Atividade Windows aberta, pressione a tecla Print Screen ou PrtSc no teclado.
  2. Abra o Paint:
    • Menu Iniciar → Digite Paint → Abrir.
  3. Aperte Ctrl + V (Primeiro aperte CTRL e logo depois o V), para colar a imagem.
  4. Clique em Arquivo → Salvar como → Imagem BMP.
  5. Salve o arquivo com o nome:
    print_atividade.bmp
  6. Escolha a pasta Print para salvar.
