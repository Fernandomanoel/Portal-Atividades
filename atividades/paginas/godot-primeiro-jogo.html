🎯 O que vamos construir

Nesta atividade você vai montar um jogo pequeno, mas completo, do início ao fim: um jogador controlado pelas setas do teclado que precisa tocar em uma moeda para vencer. É o exercício clássico para aprender os três pilares de qualquer jogo 2D na Godot: Nodes com física (o jogador), Nodes de detecção (a moeda) e código GDScript (o movimento e a lógica de vitória).

Pré-requisito

Esta atividade parte do zero, mas usa os mesmos conceitos de Node, Inspector e cena vistos na atividade "Conhecendo o Godot". Se ainda tem dúvida sobre o que é um Node ou como usar o Inspector, vale revisar aquela atividade antes de continuar.

1️⃣ Criando o projeto

  1. Abra o Godot.
  2. Clique em New Project.
  3. Nome do projeto: Pegue a Moeda
  4. Clique em Create & Edit.

2️⃣ Criando o jogador

O jogador precisa de três coisas: um "corpo" que se move e colide com o cenário, uma imagem para aparecer na tela, e uma forma de colisão que define os limites físicos desse corpo.

  1. Clique em + para adicionar o primeiro Node da cena.
  2. Adicione um CharacterBody2D.
  3. Renomeie para: Jogador
  4. Adicione como filho: Sprite2D
  5. Escolha uma imagem qualquer para o Texture do Sprite2D.
  6. Adicione também: CollisionShape2D
  7. No Inspector do CollisionShape2D, defina o Shape como RectangleShape2D.
  8. Ajuste o tamanho do retângulo para cobrir o personagem.

3️⃣ Criando a moeda

A moeda não precisa colidir fisicamente com nada — ela só precisa perceber quando o jogador chega perto. Por isso ela usa um tipo de Node diferente do jogador (veja o comparativo logo abaixo).

  1. Volte para a cena principal.
  2. Adicione um Area2D.
  3. Renomeie para: Moeda
  4. Adicione como filho: Sprite2D
  5. Escolha uma imagem de moeda.
  6. Adicione também: CollisionShape2D
  7. Ajuste o tamanho da forma de colisão para cobrir a moeda.
  8. Posicione a moeda longe do jogador na Viewport, usando a ferramenta de movimentação.

CharacterBody2D × Area2D — qual a diferença?

🧍 CharacterBody2D (Jogador)

É um Node feito para objetos que se movem e colidem de verdade com o cenário: ele é barrado por paredes, para em cima de plataformas, empurra e é empurrado. É o tipo certo para personagens controláveis. Junto com um CollisionShape2D, ele define um "corpo sólido" que a física do jogo respeita.

🪙 Area2D (Moeda)

É um Node que define uma zona de detecção, sem física de colisão sólida — nada é barrado por ela, os objetos simplesmente atravessam. O que ela sabe fazer é avisar quando algo entra ou sai dessa zona, através de um sinal. É exatamente o que uma moeda precisa: não deve travar o jogador, só perceber quando ele chega perto para então "ser coletada".

💡 Regra prática: se o objeto precisa bloquear ou ser bloqueado fisicamente, use CharacterBody2D (ou StaticBody2D/RigidBody2D para cenário e objetos com física). Se o objeto só precisa perceber contato — moedas, gatilhos, áreas de dano, portas invisíveis — use Area2D.

4️⃣ Criando o texto de vitória

  1. Adicione um Label na cena principal.
  2. Digite o texto: VOCÊ GANHOU!
  3. No Inspector, aumente o tamanho da fonte (procure por Theme Overrides > Font Sizes) para que fique bem visível.
  4. Desmarque a propriedade Visible no Inspector, deixando o texto invisível no início do jogo — ele só deve aparecer quando o jogador vencer.

5️⃣ Programando o movimento

Chegou a hora de dar vida ao Jogador com código. Selecione o Node Jogador, clique com o botão direito e escolha Attach Script (Anexar Script) para criar um novo arquivo GDScript, e cole o código abaixo:

Jogador.gd
extends CharacterBody2D var velocidade = 200 func _physics_process(delta): var direcao = Vector2.ZERO if Input.is_action_pressed("ui_right"): direcao.x += 1 if Input.is_action_pressed("ui_left"): direcao.x -= 1 if Input.is_action_pressed("ui_down"): direcao.y += 1 if Input.is_action_pressed("ui_up"): direcao.y -= 1 velocity = direcao.normalized() * velocidade move_and_slide()

Entendendo o código linha por linha

TrechoO que significa
extends CharacterBody2DToda script GDScript começa dizendo qual tipo de Node ela está controlando. Aqui, o script "estende" (herda de) CharacterBody2D — ou seja, além de tudo que esse Node já sabe fazer sozinho, ele ganha o comportamento que vamos escrever.
var velocidade = 200var declara uma variável — um espaço com nome para guardar um valor que pode mudar. Aqui criamos velocidade guardando 200, que representa a rapidez do jogador em pixels por segundo. Por estar fora de qualquer função, ela existe durante todo o jogo e pode ser lida em qualquer parte do script.
func _physics_process(delta):func declara uma função (um bloco de código nomeado). _physics_process é uma função especial que a própria Godot chama automaticamente a cada quadro de física (dezenas de vezes por segundo), o lugar certo para código de movimento. O parâmetro delta é o tempo em segundos desde o último quadro — útil para movimentos que dependem de tempo real, embora não seja usado diretamente neste script.
var direcao = Vector2.ZEROCria uma variável local (só existe dentro desta função) chamada direcao, do tipo Vector2 — um par de números (x, y) usado para representar posições e direções em 2D. Vector2.ZERO é um atalho para (0, 0): começamos assumindo que o jogador não está se movendo para nenhum lado.
Input.is_action_pressed("ui_right")Input é o sistema da Godot que sabe o que o jogador está apertando no teclado, mouse ou controle. is_action_pressed(...) pergunta "essa tecla está pressionada agora?". "ui_right", "ui_left", "ui_up" e "ui_down" são ações já configuradas por padrão em todo projeto Godot, ligadas às setas do teclado.
direcao.x += 1 / direcao.y -= 1 etc.Cada if soma ou subtrai 1 do eixo x ou y de direcao conforme a tecla correspondente estiver pressionada. Se o jogador apertar duas setas ao mesmo tempo (como direita + baixo), os dois eixos são ajustados juntos, resultando num movimento diagonal.
velocity = direcao.normalized() * velocidadevelocity é uma propriedade especial já embutida em todo CharacterBody2D — é ela que controla para onde e quão rápido o corpo se move. normalized() "corrige" o vetor direcao para ter sempre o mesmo comprimento (1), mesmo na diagonal — sem isso, o jogador se moveria mais rápido na diagonal do que na horizontal ou vertical, porque x e y somados diagonalmente resultam num vetor maior. Multiplicar pela velocidade aplica a rapidez desejada.
move_and_slide()Função pronta do CharacterBody2D que efetivamente move o corpo na direção de velocity, respeitando colisões com paredes e o cenário — "deslizando" ao longo de obstáculos em vez de travar bruscamente neles.

6️⃣ Detectando a moeda

Agora precisamos que o jogo perceba quando o Jogador toca a Moeda. Para isso usamos um sinal.

O que é um sinal (signal) na Godot?

Um sinal é um aviso que um Node emite quando algo acontece com ele — como um alarme que dispara sozinho. Você não precisa ficar checando "a moeda foi tocada?" a cada quadro; em vez disso, você conecta uma função ao sinal, e a Godot chama essa função automaticamente no momento certo. O Area2D já vem com um sinal chamado body_entered, que dispara sempre que um corpo físico (como o nosso CharacterBody2D) entra na área de colisão dele.

  1. Selecione o Node Moeda.
  2. Abra a aba Node (ao lado do Inspector) para ver a lista de sinais disponíveis.
  3. Dê um duplo clique no sinal body_entered e conecte-o à cena principal — a Godot cria automaticamente uma função vazia pronta para receber esse aviso.
  4. Complete a função com o código abaixo:
CenaPrincipal.gd
func _on_moeda_body_entered(body): $Label.visible = true $Moeda.queue_free()
TrechoO que significa
func _on_moeda_body_entered(body):Essa é a função chamada automaticamente pelo sinal body_entered. O parâmetro body é preenchido pela própria Godot com uma referência ao corpo físico que entrou na área — no nosso caso, o Jogador.
$Label.visible = trueO $ é um atalho da Godot para "buscar um Node filho pelo nome" — aqui, o Node Label. Alterar sua propriedade visible para true faz o texto "VOCÊ GANHOU!" aparecer na tela, que estava escondido desde a Parte 4.
$Moeda.queue_free()queue_free() é o comando padrão da Godot para remover um Node do jogo de forma segura. Aqui, a própria moeda se remove assim que é coletada, para não continuar aparecendo na tela.

🚀 E se... (para ir além)

O jogo básico está funcionando — mas um bom jeito de aprender de verdade é modificar e quebrar as coisas por conta própria. Algumas ideias para testar sozinho:

  • E se você adicionar uma segunda moeda? Duplique o Node Moeda (Ctrl+D), posicione em outro lugar da tela e conecte o sinal body_entered dela também. Repare que vai precisar de uma função separada (ou adaptar a mesma) para cada moeda.
  • E se você criar um contador de moedas coletadas? Adicione uma variável global (por exemplo var pontos = 0 no script da cena principal) e some 1 a ela dentro de _on_moeda_body_entered. Depois exiba esse número em um Label separado, atualizando o texto com algo como $LabelPontos.text = str(pontos).
  • E se, em vez do texto de vitória, você tocasse um som? Adicione um Node AudioStreamPlayer2D com um efeito sonoro de moeda e chame $AudioStreamPlayer2D.play() dentro da mesma função — o texto e o som podem, inclusive, acontecer juntos.
