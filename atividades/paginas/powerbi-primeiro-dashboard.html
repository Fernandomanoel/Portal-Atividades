🎯 Objetivo

Nesta atividade você vai aprender a:

  • Importar dados
  • Criar gráficos
  • Montar um painel básico

1️⃣ Passo 1: Crie a Planilha por meio do Excel 2021

Você pode criar uma tabela simples no Excel com estes dados:

ABCD
1ProdutoCategoriaVendasData
2AEletrônicos10001/01/2024
3BRoupas20002/01/2024
4CEletrônicos25003/01/2024
5DAlimentos15004/01/2024

No Excel, clique em Arquivo:

  1. Clique em Salvar Como
  2. Escolha Este Computador
  3. Clique em Documentos (ou "Documents")
  4. Dê um nome para o arquivo
  5. Clique em Salvar

2️⃣ Passo 2: Importar dados no Power BI

Abra o Power BI:

  1. Clique em "Obter Dados"
  2. Escolha Excel ou CSV
  3. Selecione seu arquivo
  4. Clique em Carregar

3️⃣ Passo 3: Criar visualizações

Agora vem a parte mais legal:

1. Gráfico de colunas

Arraste:

  • Produto → Eixo
  • Vendas → Valores

2. Gráfico de pizza

Arraste:

  • Categoria → Legenda
  • Vendas → Valores

4️⃣ Passo 4: Filtro por data

  • Adicione um segmentador
  • Coloque o campo Data
  • Agora você pode filtrar os dados interativamente

5️⃣ Passo 5: Personalizar

  • Clique nos gráficos
  • Vá em "Formatar" (ícone de rolinho)
  • Mude cores, títulos e estilos
