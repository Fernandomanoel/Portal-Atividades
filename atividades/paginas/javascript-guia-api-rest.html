    1. Fundamentos de API REST

    O que é uma API?

    Uma API (Application Programming Interface) é um conjunto de regras e protocolos que permite que diferentes aplicações se comuniquem. Uma API REST usa o protocolo HTTP para operações CRUD (Create, Read, Update, Delete).

    Princípios REST

    • Cliente-Servidor: Separação clara entre cliente e servidor
    • Stateless: Cada requisição contém todas as informações necessárias
    • Recursos: Dados são representados como recursos (URLs)
    • Métodos HTTP: GET, POST, PUT, DELETE, PATCH
    • Representação: Dados geralmente em JSON

    Métodos HTTP

    Método Operação Exemplo
    GET Obter dados (ler) GET /api/usuarios/1
    POST Criar dados POST /api/usuarios
    PUT Atualizar dados completo PUT /api/usuarios/1
    PATCH Atualizar dados parcial PATCH /api/usuarios/1
    DELETE Deletar dados DELETE /api/usuarios/1

    💡 Exemplos de URLs REST

    GET /api/usuarios — Lista todos os usuários

    GET /api/usuarios/123 — Pega usuário com ID 123

    POST /api/usuarios — Cria novo usuário

    PUT /api/usuarios/123 — Atualiza usuário 123

    DELETE /api/usuarios/123 — Deleta usuário 123

    Status HTTP

    Código Significado Exemplo
    200 OK - Sucesso Dados obtidos com sucesso
    201 Created - Criado Novo recurso criado
    400 Bad Request - Erro do cliente Dados inválidos enviados
    404 Not Found - Não encontrado Recurso não existe
    500 Server Error - Erro do servidor Erro interno no servidor

    2. Configuração Inicial - Node.js e npm

    Instalando Node.js

    1. Acesse nodejs.org
    2. Baixe a versão LTS (Long Term Support)
    3. Execute o instalador
    4. Verifique a instalação: node --version e npm --version

    Criando seu primeiro projeto

    Abra o terminal no VS Code (Ctrl + `) e execute:

    Terminal
    mkdir minha-api cd minha-api npm init -y

    Isso criará um arquivo package.json com configurações do projeto.

    Instalando dependências

    Você precisa do Express (framework web) e Nodemon (reinicia servidor automaticamente):

    Terminal
    npm install express npm install --save-dev nodemon

    Configurar script no package.json

    Abra package.json e substitua a linha de "scripts" por:

    package.json
    "scripts": { "start": "node index.js", "dev": "nodemon index.js" }
    ✅ Seu projeto está pronto! Agora vamos criar o servidor.

    3. Seu Primeiro Servidor Express

    Criando index.js

    Crie um arquivo chamado index.js na raiz do projeto:

    index.js - Servidor Básico
    // Importar Express const express = require('express'); // Criar aplicação const app = express(); // Middleware: aceitar JSON app.use(express.json()); // Porta do servidor const PORT = 3000; // Rota GET simples app.get('/api/oi', (req, res) => { res.json({ mensagem: 'Olá, API!' }); }); // Iniciar servidor app.listen(PORT, () => { console.log(`Servidor rodando em http://localhost:${PORT}`); });

    Rodando o servidor

    No terminal, execute:

    Terminal
    npm run dev

    Você verá: Servidor rodando em http://localhost:3000

    Testando a API

    Abra o navegador e acesse: http://localhost:3000/api/oi

    Você verá: {"mensagem":"Olá, API!"}

    ✅ Parabéns! Seu primeiro servidor Express está rodando!

    4. Rotas e Parâmetros

    Diferentes tipos de rotas

    Rota com parâmetro de caminho (path parameter)

    index.js
    // /:id é um parâmetro app.get('/api/usuarios/:id', (req, res) => { const { id } = req.params; res.json({ mensagem: `Usuário com ID: ${id}`, id: id }); });

    Teste: http://localhost:3000/api/usuarios/42

    Resposta: {"mensagem":"Usuário com ID: 42","id":"42"}

    Rota com query string

    index.js
    // ?nome=João&idade=25 app.get('/api/buscar', (req, res) => { const { nome, idade } = req.query; res.json({ nome, idade }); });

    Teste: http://localhost:3000/api/buscar?nome=João&idade=25

    POST - Receber dados no corpo

    index.js
    app.post('/api/usuarios', (req, res) => { const { nome, email } = req.body; // Validação simples if (!nome || !email) { return res.status(400).json({ erro: 'Nome e email são obrigatórios' }); } res.status(201).json({ mensagem: 'Usuário criado!', usuario: { nome, email } }); });
    💡 Use ferramentas como Postman ou Insomnia para testar POST, PUT, DELETE. Ou use curl no terminal!

    5. Estrutura de Dados - Banco em Memória

    Criar um banco de dados simples em memória

    Para aprender, vamos usar um array para armazenar dados. Depois aprenderemos banco de dados real.

    index.js - Com dados em memória
    const express = require('express'); const app = express(); app.use(express.json()); // Simular banco de dados let usuarios = [ { id: 1, nome: 'João', email: 'joao@example.com' }, { id: 2, nome: 'Maria', email: 'maria@example.com' } ]; let proximoId = 3; // GET - Listar todos app.get('/api/usuarios', (req, res) => { res.json(usuarios); }); // GET - Obter um por ID app.get('/api/usuarios/:id', (req, res) => { const usuario = usuarios.find(u => u.id === parseInt(req.params.id)); if (!usuario) { return res.status(404).json({ erro: 'Usuário não encontrado' }); } res.json(usuario); }); // POST - Criar novo app.post('/api/usuarios', (req, res) => { const { nome, email } = req.body; if (!nome || !email) { return res.status(400).json({ erro: 'Nome e email obrigatórios' }); } const novoUsuario = { id: proximoId++, nome, email }; usuarios.push(novoUsuario); res.status(201).json(novoUsuario); }); // PUT - Atualizar app.put('/api/usuarios/:id', (req, res) => { const usuario = usuarios.find(u => u.id === parseInt(req.params.id)); if (!usuario) { return res.status(404).json({ erro: 'Usuário não encontrado' }); } if (req.body.nome) usuario.nome = req.body.nome; if (req.body.email) usuario.email = req.body.email; res.json(usuario); }); // DELETE - Deletar app.delete('/api/usuarios/:id', (req, res) => { const indice = usuarios.findIndex(u => u.id === parseInt(req.params.id)); if (indice === -1) { return res.status(404).json({ erro: 'Usuário não encontrado' }); } const usuarioDeletado = usuarios.splice(indice, 1); res.json({ mensagem: 'Usuário deletado', usuario: usuarioDeletado[0] }); }); app.listen(3000, () => { console.log('Servidor em http://localhost:3000'); });

    Testando com curl

    No terminal, teste seus endpoints:

    Terminal - Testar GET
    curl http://localhost:3000/api/usuarios
    Terminal - Testar POST
    curl -X POST http://localhost:3000/api/usuarios \ -H "Content-Type: application/json" \ -d '{"nome":"Pedro","email":"pedro@example.com"}'
    ✅ Agora você tem uma API CRUD completa funcionando!

    6. Banco de Dados - MongoDB com Mongoose

    Por que usar MongoDB?

    • Banco de dados NoSQL (flexível)
    • Armazena dados em formato JSON
    • Fácil de usar com JavaScript
    • Escalável para aplicações grandes

    Instalação

    Terminal
    npm install mongoose

    Conectar ao MongoDB

    Crie uma conta grátis no MongoDB Atlas

    index.js - Com MongoDB
    const mongoose = require('mongoose'); // Conectar ao banco mongoose.connect('mongodb+srv://usuario:senha@cluster.mongodb.net/meuBanco', { useNewUrlParser: true, useUnifiedTopology: true }).then(() => console.log('MongoDB conectado')) .catch(err => console.log('Erro ao conectar:', err)); // Definir esquema (estrutura) const usuarioSchema = new mongoose.Schema({ nome: { type: String, required: true }, email: { type: String, required: true, unique: true }, idade: Number, dataCriacao: { type: Date, default: Date.now } }); // Criar modelo const Usuario = mongoose.model('Usuario', usuarioSchema);

    CRUD com MongoDB

    index.js - Rotas com MongoDB
    // GET - Listar todos app.get('/api/usuarios', async (req, res) => { try { const usuarios = await Usuario.find(); res.json(usuarios); } catch (err) { res.status(500).json({ erro: err.message }); } }); // POST - Criar app.post('/api/usuarios', async (req, res) => { try { const novoUsuario = new Usuario(req.body); const usuario = await novoUsuario.save(); res.status(201).json(usuario); } catch (err) { res.status(400).json({ erro: err.message }); } }); // PUT - Atualizar app.put('/api/usuarios/:id', async (req, res) => { try { const usuario = await Usuario.findByIdAndUpdate( req.params.id, req.body, { new: true } ); res.json(usuario); } catch (err) { res.status(500).json({ erro: err.message }); } }); // DELETE - Deletar app.delete('/api/usuarios/:id', async (req, res) => { try { const usuario = await Usuario.findByIdAndDelete(req.params.id); res.json({ mensagem: 'Deletado com sucesso', usuario }); } catch (err) { res.status(500).json({ erro: err.message }); } });
    💡 Note o uso de async/await para operações assíncronas com o banco!

    7. Middlewares e Tratamento de Erros

    O que é um Middleware?

    Um middleware é uma função que pode processar requisições e respostas antes de chegar à rota final. Útil para:

    • Validar dados
    • Autenticação
    • Logging
    • Tratamento de erros

    Middleware simples de logging

    index.js
    // Middleware que registra todas as requisições app.use((req, res, next) => { const tempo = new Date().toLocaleTimeString(); console.log(`[${tempo}] ${req.method} ${req.path}`); next(); // Continua para próxima função });

    Middleware de validação

    index.js
    // Middleware que valida email const validarEmail = (req, res, next) => { const { email } = req.body; const emailRegex = /^[^@]+@[^@]+\.[^@]+$/; if (!emailRegex.test(email)) { return res.status(400).json({ erro: 'Email inválido' }); } next(); }; // Usar o middleware em uma rota específica app.post('/api/usuarios', validarEmail, (req, res) => { // Criar usuário... res.json({ mensagem: 'Usuário criado' }); });

    Tratamento global de erros

    index.js - Middleware de erro
    // Colocar NO FINAL do arquivo, depois de todas as rotas app.use((err, req, res, next) => { console.error('Erro:', err.message); res.status(500).json({ erro: err.message || 'Erro interno do servidor' }); });

    8. Autenticação com JWT

    O que é JWT?

    JWT (JSON Web Token) é um padrão seguro de autenticação. Permite verificar a identidade do usuário sem armazenar sessões no servidor.

    Instalando dependências

    Terminal
    npm install jsonwebtoken bcryptjs dotenv

    Criar arquivo .env

    Crie um arquivo .env na raiz do projeto:

    .env
    MONGODB_URI=mongodb+srv://usuario:senha@cluster.mongodb.net/meuBanco JWT_SECRET=sua_chave_super_secreta_aqui PORT=3000

    Implementar autenticação

    index.js - Autenticação JWT
    require('dotenv').config(); const jwt = require('jsonwebtoken'); const bcrypt = require('bcryptjs'); // Middleware para verificar token const verificarToken = (req, res, next) => { const token = req.headers['authorization']?..split(' ')[1]; if (!token) { return res.status(401).json({ erro: 'Token não fornecido' }); } try { const decodificado = jwt.verify(token, process.env.JWT_SECRET); req.usuarioId = decodificado.id; next(); } catch (err) { res.status(401).json({ erro: 'Token inválido' }); } }; // Rota de login app.post('/api/login', async (req, res) => { try { const { email, senha } = req.body; // Encontrar usuário const usuario = await Usuario.findOne({ email }); if (!usuario) { return res.status(400).json({ erro: 'Usuário não encontrado' }); } // Verificar senha const senhaCorreta = await bcrypt.compare(senha, usuario.senha); if (!senhaCorreta) { return res.status(400).json({ erro: 'Senha incorreta' }); } // Criar token const token = jwt.sign( { id: usuario._id }, process.env.JWT_SECRET, { expiresIn: '7d' } ); res.json({ token, usuario: { id: usuario._id, email: usuario.email } }); } catch (err) { res.status(500).json({ erro: err.message }); } }); // Rota protegida - só acessa com token válido app.get('/api/perfil', verificarToken, async (req, res) => { try { const usuario = await Usuario.findById(req.usuarioId); res.json(usuario); } catch (err) { res.status(500).json({ erro: err.message }); } });
    💡 Sempre use HTTPS em produção para proteger tokens!

    models/Usuario.js

    models/Usuario.js
    const mongoose = require('mongoose'); const usuarioSchema = new mongoose.Schema({ nome: { type: String, required: true }, email: { type: String, required: true, unique: true }, senha: { type: String, required: true }, dataCriacao: { type: Date, default: Date.now } }); module.exports = mongoose.model('Usuario', usuarioSchema);

    routes/usuarios.js

    routes/usuarios.js
    const express = require('express'); const router = express.Router(); const usuarioController = require('../controllers/usuarioController'); const verificarToken = require('../middlewares/autenticacao'); router.get('/', usuarioController.listarUsuarios); router.get('/:id', usuarioController.obterUsuario); router.post('/', usuarioController.criarUsuario); router.put('/:id', verificarToken, usuarioController.atualizarUsuario); router.delete('/:id', verificarToken, usuarioController.deletarUsuario); module.exports = router;

    controllers/usuarioController.js

    controllers/usuarioController.js
    const Usuario = require('../models/Usuario'); exports.listarUsuarios = async (req, res) => { try { const usuarios = await Usuario.find(); res.json(usuarios); } catch (err) { res.status(500).json({ erro: err.message }); } }; exports.criarUsuario = async (req, res) => { try { const novoUsuario = new Usuario(req.body); const usuario = await novoUsuario.save(); res.status(201).json(usuario); } catch (err) { res.status(400).json({ erro: err.message }); } };

    index.js - Usando as rotas

    index.js - Versão limpa
    require('dotenv').config(); const express = require('express'); const mongoose = require('mongoose'); const app = express(); // Middlewares app.use(express.json()); // Conectar ao banco mongoose.connect(process.env.MONGODB_URI) .then(() => console.log('MongoDB conectado')) .catch(err => console.log('Erro no banco:', err)); // Importar rotas const usuariosRoutes = require('./routes/usuarios'); // Usar rotas app.use('/api/usuarios', usuariosRoutes); // Iniciar servidor app.listen(process.env.PORT || 3000, () => { console.log(`Servidor em porta ${process.env.PORT || 3000}`); });

    10. Deploy - Colocando a API em Produção

    Opções de Deploy

    • Heroku: Gratuito, fácil (deixou de ser 100% grátis)
    • Railway: Alternativa ao Heroku, gratuita
    • Render: Fácil e gratuito
    • AWS/Google Cloud: Profissional e escalável

    Deploy no Render (recomendado)

    1. Crie conta em render.com
    2. Conecte seu repositório GitHub
    3. Clique em "New" → "Web Service"
    4. Selecione seu repositório
    5. Configure:
      • Build Command: npm install
      • Start Command: npm start
    6. Adicione variáveis de ambiente (.env)
    7. Deploy automático ao fazer push no Git

    Preparar para produção

    Adicione no seu package.json:

    package.json
    "scripts": { "start": "node index.js", "dev": "nodemon index.js" }, "engines": { "node": "18.x" }

    Checklist de produção

    ✓ Antes de fazer deploy:

    • ✅ HTTPS configurado
    • ✅ Variáveis sensíveis em .env
    • ✅ Tratamento de erros implementado
    • ✅ Autenticação JWT funcionando
    • ✅ CORS configurado (se necessário)
    • ✅ Rate limiting implementado
    • ✅ Logs configurados
    • ✅ Testes automatizados
    • ✅ .env não committed no Git
    • ✅ Banco de dados em produção

    Configurar CORS

    index.js - CORS
    const cors = require('cors'); app.use(cors({ origin: 'https://meu-frontend.vercel.app', credentials: true }));

    Primeiro instale: npm install cors

    12. Recursos Avançados e Melhores Práticas

    Paginação

    index.js - Paginação
    app.get('/api/usuarios', async (req, res) => { const page = parseInt(req.query.page) || 1; const limit = 10; const skip = (page - 1) * limit; const usuarios = await Usuario.find() .skip(skip) .limit(limit); const total = await Usuario.countDocuments(); res.json({ usuarios, paginaAtual: page, totalPaginas: Math.ceil(total / limit), total }); });

    Busca e filtro

    index.js - Busca
    app.get('/api/usuarios/busca', async (req, res) => { const { nome } = req.query; const usuarios = await Usuario.find({ nome: { $regex: nome, $options: 'i' } // Case-insensitive }); res.json(usuarios); });

    Rate Limiting (proteção contra ataques)

    Terminal
    npm install express-rate-limit
    index.js - Rate Limit
    const rateLimit = require('express-rate-limit'); const limiter = rateLimit({ windowMs: 15 * 60 * 1000, // 15 minutos max: 100 // máximo 100 requisições }); app.use('/api/', limiter);

    Terminal
    npm install joi
