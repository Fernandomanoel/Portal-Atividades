🎲 Atividade 4 — Jogo de Adivinhação com Tentativas Limitadas

Atividade Complementar — JavaScript

← Voltar para Javascript

🎯 Objetivo

Criar um programa que:

  1. Gere um número aleatório de 1 a 50
  2. Dê no máximo 5 tentativas para o usuário acertar
  3. Informe se o número digitado é:
    • Maior
    • Menor
  4. Se acertar → mostrar vitória
  5. Se acabar as tentativas → mostrar derrota

🚀 Você vai treinar

  • ✅ Variáveis
  • ✅ Math.random()
  • ✅ parseInt
  • ✅ while
  • ✅ if / else
  • ✅ Contador de tentativas
  • ✅ Comparações matemáticas

🧩 Parte 1 – Criando a função

Criamos a função principal.

🧩 Parte 2 – Gerando número aleatório

let numeroSecreto = Math.floor(Math.random() * 50) + 1;

Vamos entender:

  • Math.random() → gera número entre 0 e 1
  • * 50 → transforma em 0 a 49
  • Math.floor() → arredonda para baixo
  • + 1 → faz ficar entre 1 e 50

🧩 Parte 3 – Criando controle de tentativas

let tentativas = 5; let acertou = false;
  • tentativas controla quantas chances restam
  • acertou controla se o jogador venceu

🧩 Parte 4 – Criando o WHILE

while (tentativas > 0 && !acertou) {

O loop continua enquanto:

  • Ainda houver tentativas
  • E o jogador não tiver acertado

🧩 Parte 5 – Pedindo número

let chute = parseInt(prompt("Digite um número entre 1 e 50:"));

Usuário tenta adivinhar.

🧩 Parte 6 – Verificando

if (chute === numeroSecreto) { console.log("Parabéns! Você acertou!"); acertou = true;

Se acertar:

  • Mostra mensagem
  • Muda acertou para true
} else if (chute < numeroSecreto) { console.log("O número secreto é MAIOR.");

Se o chute for menor → damos dica.

} else { console.log("O número secreto é MENOR."); }

Se não for menor nem igual → é maior.

🧩 Parte 7 – Diminuindo tentativas

tentativas--; console.log("Tentativas restantes:", tentativas);

Reduzimos 1 tentativa.

Fechamos o while:

}

🧩 Parte 8 – Se perder

if (!acertou) { console.log("Você perdeu! O número era:", numeroSecreto); }

Se saiu do loop sem acertar → perdeu.

✅ Código Completo

function jogoAdivinhacao() { let numeroSecreto = Math.floor(Math.random() * 50) + 1; let tentativas = 5; let acertou = false; while (tentativas > 0 && !acertou) { let chute = parseInt(prompt("Digite um número entre 1 e 50:")); if (chute === numeroSecreto) { console.log("Parabéns! Você acertou!"); acertou = true; } else if (chute < numeroSecreto) { console.log("O número secreto é MAIOR."); } else { console.log("O número secreto é MENOR."); } tentativas--; console.log("Tentativas restantes:", tentativas); } if (!acertou) { console.log("Você perdeu! O número era:", numeroSecreto); } } jogoAdivinhacao();
