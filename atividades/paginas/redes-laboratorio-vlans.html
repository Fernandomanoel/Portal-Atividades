02) Montar a topologia

⚠️ Esta segunda parte do material propõe um exercício introdutório de bancada com um único switch, separado da topologia principal (S1/S2/S3) mostrada acima. Mantivemos exatamente como está no PDF original — pratique primeiro este exercício simples, depois aplique os mesmos comandos na topologia completa dos três switches.

Crie:

PC0 --------\ \ PC1 ---------- SW1 / PC2 --------/

Arraste um 2960 Switch.

  • Adicione 3 PCs.
  • Conecte usando Copper Straight Through:
  • PC0 → Fa0/1
  • PC1 → Fa0/2
  • PC2 → Fa0/3

Abra a configuração do switch

  • Clique duas vezes no switch.
  • Abrirá uma janela.
  • Clique na aba CLI.

Entrar no modo privilegiado

Digite após aparecer Switch>

enable

E pressione o ENTER

Agora aparecerá:

Switch#

Entrar no modo de configuração

Digite:

Configure terminal

Ou

Conf t

Criar uma VLAN

Digite uma linha por vez:

Vlan 10

E dê o ENTER

Resultado:

Switch(config-vlan)#

Criar as VLANs no S1

vlan 10 name DOCENTES exit vlan 20 name ALUNOS exit vlan 30 name CONVIDADOS exit vlan 99 name NATIVA exit
  • Repita os mesmos comandos no S2
  • E repita os mesmos comandos no S3

🔗 Configurar os troncos

As portas Fa0/1 até Fa0/5 serão troncos.

Digite:

interface range fa0/1-5 switchport mode trunk switchport trunk native vlan 99 switchport trunk allowed vlan 10,20,30,99 exit
  • interface range fa0/1-5 → seleciona Fa0/1, Fa0/2, Fa0/3, Fa0/4 e Fa0/5.
  • switchport mode trunk → transforma as portas em troncos.
  • switchport trunk native vlan 99 → define VLAN 99 como nativa

👤 Configurar VLAN 30 (Convidados)

Portas Fa0/6 até Fa0/10:

interface range fa0/6-10 switchport mode access switchport access vlan 30 exit

🧑‍🏫 Configurar VLAN 10 (Docentes)

Portas Fa0/11 até Fa0/17:

interface range fa0/11-17 switchport mode access switchport access vlan 10 exit

🎓 Configurar VLAN 20 (Alunos)

Portas Fa0/18 até Fa0/24:

interface range fa0/18-24 switchport mode access switchport access vlan 20 exit

🔎 Verifique

show vlan brief
