🗑️ Desinstalar o Avast no Windows 11

Windows 11

← Voltar para Windows 11

🎯 Objetivo

Aprender a desinstalar um programa no Windows 11 utilizando as Configurações do sistema.

1️⃣ Passo 1 — Abrir as Configurações

  1. Clique no Menu Iniciar.
  2. Clique em Configurações.

2️⃣ Passo 2 — Acessar Aplicativos

  1. No menu lateral, clique em Aplicativos.
  2. Em seguida, clique em Aplicativos instalados.

3️⃣ Passo 3 — Localizar o Avast

  1. Na lista de programas, procure por Avast Antivirus.
  2. Clique nos três pontinhos (⋮) ao lado do nome.

4️⃣ Passo 4 — Desinstalar

  1. Clique em Desinstalar.
  2. Confirme novamente em Desinstalar.
  3. Aguarde o processo finalizar.
  4. Se o sistema pedir, reinicie o computador.

5️⃣ Passo 5 — Tire Print

  1. No Explorador de Arquivos crie uma pasta em Documentos.
  2. O nome desta pasta para colocar "Atividade Windows".
  3. Tire print da tela onde está "Avast Desinstalado", aperte o ícone do Windows do Teclado + PrtSc (Ambos juntos).
  4. Abra o programa Paint.
  5. Aperte CTRL + V, dentro do Paint.
  6. Salve o arquivo do Paint na pasta que você criou.
