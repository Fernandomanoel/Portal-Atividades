🛠️ Montando a rede

Abra o Cisco Packet Tracer.

Equipamentos

Adicione:

  • 1 Router 1941
  • 2 PCs

Conecte

  • PC-A → R1 G0/0
  • PC-B → R1 G0/1

🖥️ Configurar os computadores

PC-A

Desktop → IP Configuration

No Cisco, você tem que fixar o IP dos computadores.

CampoValor
IP Address192.168.1.10
Subnet Mask255.255.255.0
Gateway192.168.1.1

PC-B

Desktop → IP Configuration

CampoValor
IP Address192.168.2.10
Subnet Mask255.255.255.0
Gateway192.168.2.1

⚙️ Configurar o roteador

R1 → CLI

Digite dentro do terminal do Roteador:

enable

Depois digite:

Configure terminal

Configurar o G0/0

Digite o comando abaixo:

interface g0/0 ip address 192.168.1.1 255.255.255.0 no shutdown exit

Configurar o G0/1

Digite:

interface g0/1 ip address 192.168.2.1 255.255.255.0 no shutdown exit

Verificar

Digite:

show ip interface brief

As interfaces devem aparecer como abaixo:

GigabitEthernet0/0 up up GigabitEthernet0/1 up up

✅ Testar

No PC-A você abre o DESKTOP e logo após Command Prompt, digite os comandos abaixo:

Teste:

Ping 192.168.1.1

E depois:

Ping 192.168.2.10
