Avaliação Prática de Windows 11

Instruções Gerais

Nesta avaliação, focaremos no uso de ferramentas do sistema, gerenciamento de recursos e produtividade no Windows 11.

  • Para cada tarefa concluída, você deverá registrar uma captura de tela (Print) usando o atalho Windows + Shift + S.
  • Salve todos os prints temporariamente na sua Área de Trabalho para facilitar a organização no final da prova.
  • Certifique-se de nomear os arquivos exatamente como solicitado para que a estrutura fique correta no momento da entrega.

Tarefa 1: Informações do Sistema

Objetivo: Identificar a versão do Windows e as especificações de hardware do computador.
  1. Abra as Configurações do Windows (atalho: Windows + I).
  2. No menu lateral esquerdo, certifique-se de estar na aba Sistema.
  3. Role a página até o final e clique em Sobre.
  4. Nesta tela, você verá as especificações do dispositivo (como processador e RAM) e as especificações do Windows (edição e versão).
📷 Evidência: Tire um print da tela exibindo as "Especificações do Windows". Salve na Área de Trabalho como: Print1_Sobre.png.

Tarefa 2: Gerenciador de Tarefas e Desempenho

Objetivo: Monitorar o uso atual de recursos da máquina.
  1. Pressione simultaneamente as teclas Ctrl + Shift + Esc para abrir o Gerenciador de Tarefas.
  2. Se ele abrir em uma janela pequena, clique em "Mais detalhes" na parte inferior (se aplicável).
  3. No menu lateral esquerdo, clique no ícone de Desempenho (geralmente representado por um gráfico com uma linha).
  4. Clique em Memória para visualizar o gráfico de consumo de RAM.
📷 Evidência: Tire um print da janela do Gerenciador de Tarefas mostrando o gráfico de Memória. Salve como: Print2_Desempenho.png.

Tarefa 3: Sensor de Armazenamento

Objetivo: Configurar a limpeza automática de arquivos temporários para otimizar espaço.
  1. Abra novamente as Configurações e vá em Sistema.
  2. Clique em Armazenamento.
  3. Procure a seção "Gerenciamento de armazenamento" e localize a chave do Sensor de Armazenamento.
  4. Ative essa chave (mude para "Ativado").
📷 Evidência: Tire um print da tela garantindo que o Sensor de Armazenamento apareça ativado. Salve como: Print3_Armazenamento.png.

Tarefa 4: Áreas de Trabalho Virtuais (Task View)

Objetivo: Criar múltiplos ambientes de trabalho para separar tarefas.
  1. Clique no botão Visão de Tarefas (dois quadrados sobrepostos na barra de tarefas) ou pressione Windows + Tab.
  2. Na parte inferior ou superior da tela, clique no botão + Nova área de trabalho.
  3. Uma "Área de trabalho 2" será criada ao lado da original.
  4. Mantenha a tela de Visão de Tarefas aberta para visualizar ambas.
📷 Evidência: Com a Visão de Tarefas aberta (mostrando a Área de trabalho 1 e 2 na tela), tire um print. Salve como: Print4_AreasVirtuais.png.

Tarefa 5: Organização do Menu Iniciar

Objetivo: Fixar e reposicionar aplicativos de uso frequente para acesso rápido.
  1. Clique no botão Iniciar.
  2. Na barra de pesquisa no topo, digite "Painel de Controle".
  3. Nos resultados, clique com o botão direito sobre o Painel de Controle e escolha Fixar no Iniciar.
  4. Apague a pesquisa, abra o Menu Iniciar novamente. Role para baixo, localize o Painel de Controle recém-fixado, clique e arraste-o para a primeira linha, no topo da lista.
📷 Evidência: Tire um print do Menu Iniciar aberto, mostrando o Painel de Controle fixado na primeira linha. Salve como: Print5_MenuIniciar.png.

Tarefa 6: Estruturação, Empacotamento e Entrega

Objetivo: Organizar todas as evidências coletadas em uma estrutura de diretórios e compactar para envio.
  1. Criar a Estrutura: Abra o Explorador de Arquivos (Windows + E), vá até a pasta Documentos.
  2. Pasta Principal: Crie uma nova pasta chamada Avaliacao_Ferramentas_Win11.
  3. Subpasta: Abra esta pasta e crie uma subpasta chamada Capturas_De_Tela.
  4. Mover as Evidências: Vá até a sua Área de Trabalho, recorte (Ctrl + X) os 5 prints gerados nas tarefas anteriores e cole-os (Ctrl + V) dentro da pasta Capturas_De_Tela.
  5. Preparar para Compactação: Volte ao diretório Documentos, para que você consiga visualizar a pasta principal pelo lado de fora.
  6. Compactar em ZIP: Clique com o botão direito sobre a pasta Avaliacao_Ferramentas_Win11 e clique na opção Comprimir para arquivo ZIP.
  7. Finalização: O arquivo Avaliacao_Ferramentas_Win11.zip será criado. Este é o arquivo que contém a sua prova completa e deve ser submetido ao professor.
