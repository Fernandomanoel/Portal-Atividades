Função SE

Aprender a utilizar a função SE no Excel para calcular bônus salarial de acordo com a quantidade de faltas do funcionário.

O que é a fórmula SE?

A função SE é utilizada no Excel para realizar testes lógicos, ou seja, verificar se uma condição é verdadeira ou falsa e, a partir disso, mostrar um resultado.

A estrutura da função SE é:

SE(teste_lógico; valor_se_verdadeiro; valor_se_falso)

Entendendo cada parte da fórmula

  • Teste_lógico: é a condição que será analisada pelo Excel.
    Exemplo: verificar se o número de faltas é igual a zero.
  • Valor_se_verdadeiro: é o resultado que aparecerá caso a condição seja verdadeira.
    Exemplo: se o funcionário não tiver faltas, ele recebe o bônus de R$ 200,00.
  • Valor_se_falso: é o resultado que aparecerá caso a condição seja falsa.
    Exemplo: se o funcionário tiver uma ou mais faltas, ele não recebe bônus.

O que essa fórmula faz?

  • O Excel verifica se o valor da célula B2 é igual a 0
  • Se for verdadeiro, retorna 200
  • Se for falso, retorna 0

Atividade

Uma empresa concede um bônus de R$ 200,00 para os funcionários que não tiveram nenhuma falta no mês. Caso o funcionário tenha uma ou mais faltas, ele não receberá o bônus.

Você deverá usar a função SE para calcular automaticamente o valor do bônus.

Abra o Excel e faça esta tabela abaixo:

ABC
1BÔNUS SALARIAL
2FuncionárioFaltas no MêsBônus (R$)
3João0
4Pedrinho2
5Maria0
6Carlos1
7Ana2

Instruções

  • Observe a quantidade de faltas de cada funcionário.
  • Na coluna Bônus (R$), crie uma fórmula usando a função SE.
  • Se o número de faltas for igual a 0, o bônus será R$ 200,00.
  • Caso contrário, o bônus será R$ 0,00.
  • Copie a fórmula para as demais linhas.

O resultado tem que ser:

  • Funcionários sem faltas recebem R$ 200,00
  • Funcionários com faltas recebem R$ 0,00

Aplicando a fórmula na linha do João (linha 3):

=SE(B3=0;200;0)
  • O teste lógico: verifica se as Faltas no Mês (B3) são iguais a 0.
  • Valor se verdadeiro: se não teve faltas, o bônus é 200.
  • Valor se falso: se teve alguma falta, o bônus é 0.
⚠️ Importante: depois de digitar a fórmula na célula C3, arraste (copie) para as células C4, C5, C6 e C7, para todos os funcionários receberem o cálculo automático do bônus.
