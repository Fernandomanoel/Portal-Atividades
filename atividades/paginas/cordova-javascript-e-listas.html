Eventos, arrays e listas dinâmicas: seu app ganha vida de verdade

⏱️ Duração estimada: 2 horas

Índice

    Pré-requisito: Ionic — Prática de Componentes
    Tempo: ~2h
    Formato: prática direta, pouca teoria

    1. O Plano de Hoje

    Sua tela já existe (campo, botão, lista vazia, busca, toggle). Hoje tudo isso ganha lógica: cliques que funcionam, uma lista que aparece e desaparece de verdade, busca que filtra, ordenação, marcar como concluída. Tudo em www/js/index.js.

    Crie (ou abra) o arquivo www/js/index.js e confira que ele está carregado no fim do <body> com <script src="js/index.js"></script>.

    2. Pegando os Elementos da Tela

    Código — cole no topo do arquivo
    www/js/index.jsconst campoMissao = document.getElementById('campo-missao'); const botaoAdicionar = document.getElementById('btn-adicionar'); const listaNaTela = document.getElementById('lista-missoes'); const campoBusca = document.getElementById('busca-missao');
    Faça você: confira que os 4 id aqui batem exatamente com os do seu index.html. Se algum estiver diferente, o resto do código vai falhar em silêncio.

    3. O Array de Missões

    www/js/index.jslet missoes = [];

    Cada missão vai ser um objeto com dois dados: o texto e se está concluída.

    exemplo de item dentro do array{ texto: "Arrumar o quarto", feita: false }

    4. Clique no Botão Adicionar

    Código
    www/js/index.jsbotaoAdicionar.addEventListener('click', () => { const texto = campoMissao.value; if (texto.trim() !== "") { missoes.push({ texto: texto, feita: false }); desenharLista(); campoMissao.value = ""; } });

    .trim() remove espaços em branco do início e fim — evita adicionar uma missão "vazia" só com espaços digitados. desenharLista() ainda não existe — próximo capítulo.

    5. Desenhando a Lista na Tela

    Código
    www/js/index.jsfunction desenharLista() { listaNaTela.innerHTML = ""; missoes.forEach((missao, indice) => { const estilo = missao.feita ? "text-decoration:line-through;color:#999" : ""; listaNaTela.innerHTML += ` <ion-item> <ion-label style="${estilo}">${missao.texto}</ion-label> </ion-item> `; }); }
    Faça você: salve, rode cordova run browser, digite 3 missões diferentes e clique em adicionar em cada uma. Elas devem aparecer na lista.

    6. Botão de Excluir

    Atualize desenharLista() e adicione excluirMissao()
    www/js/index.jsfunction desenharLista() { listaNaTela.innerHTML = ""; missoes.forEach((missao, indice) => { const estilo = missao.feita ? "text-decoration:line-through;color:#999" : ""; listaNaTela.innerHTML += ` <ion-item> <ion-label style="${estilo}">${missao.texto}</ion-label> <ion-button slot="end" color="danger" fill="clear" onclick="excluirMissao(${indice})"> <ion-icon name="trash" slot="icon-only"></ion-icon> </ion-button> </ion-item> `; }); } function excluirMissao(indice) { missoes.splice(indice, 1); desenharLista(); }
    Faça você: adicione 4 missões e exclua a 2ª. Confira que sobraram as outras 3, na ordem certa.

    7. Marcar como Concluída (clique no texto)

    Adicione o onclick no ion-label e a função
    www/js/index.js — dentro do template<ion-label style="${estilo}" onclick="alternarFeita(${indice})">${missao.texto}</ion-label>
    www/js/index.js — nova funçãofunction alternarFeita(indice) { missoes[indice].feita = !missoes[indice].feita; desenharLista(); }

    !missoes[indice].feita inverte o valor: se era true vira false, e vice-versa. Clique no texto de uma missão — ela deve ficar riscada e cinza.

    8. Adicionar Apertando Enter

    Código
    www/js/index.jscampoMissao.addEventListener('keyup', (evento) => { if (evento.key === 'Enter') { botaoAdicionar.click(); // simula um clique no botão } });

    keyup dispara toda vez que uma tecla é solta. evento.key diz qual tecla foi — comparando com 'Enter', a gente reage só a ela. botaoAdicionar.click() é um truque útil: em vez de repetir a lógica de adicionar, a gente só "aperta o botão" via código.

    9. Contador de Missões

    Adicione um <p id="contador"> no HTML, acima da lista
    www/js/index.js — dentro de desenharLista()const pendentes = missoes.filter(m => !m.feita).length; document.getElementById('contador').innerText = `${pendentes} pendente(s) de ${missoes.length} no total`;

    filter() cria um novo array só com os itens que passam no teste — aqui, só as missões não concluídas (!m.feita). .length conta quantas sobraram.

    10. Busca em Tempo Real

    Código
    www/js/index.jscampoBusca.addEventListener('ionInput', (evento) => { const termo = evento.target.value.toLowerCase(); const filtradas = missoes.filter(m => m.texto.toLowerCase().includes(termo)); desenharListaFiltrada(filtradas); }); function desenharListaFiltrada(lista) { listaNaTela.innerHTML = ""; lista.forEach((missao) => { listaNaTela.innerHTML += `<ion-item><ion-label>${missao.texto}</ion-label></ion-item>`; }); }
    ⚠️ Componentes do Ionic disparam eventos com nomes próprios, começando com ion — ionInput em vez do input comum, ionChange em vez de change. É a única diferença de sintaxe ao lidar com eles.

    toLowerCase() em ambos os lados (o termo buscado e o texto da missão) faz a busca não se importar com maiúsculas/minúsculas. includes() verifica se um texto está contido dentro do outro.

    11. Ordenando a Lista

    Adicione um botão "Ordenar A-Z" no HTML com id="btn-ordenar"
    www/js/index.jsdocument.getElementById('btn-ordenar').addEventListener('click', () => { missoes.sort((a, b) => a.texto.localeCompare(b.texto)); desenharLista(); });

    sort() reordena o array no lugar. localeCompare() compara dois textos respeitando acentos e o alfabeto em português — melhor que uma comparação simples de </>, que trataria "Á" de forma estranha.

    12. Ligando o Toggle de Modo Escuro

    Código
    www/js/index.jsdocument.getElementById('toggle-tema').addEventListener('ionChange', (evento) => { document.body.style.background = evento.target.checked ? "#1a1a2e" : "#ffffff"; document.body.style.color = evento.target.checked ? "#eee" : "#333"; });

    evento.target.checked é true quando o toggle está ligado. Com uma linha, você troca o fundo e a cor do texto de todo o app — um mini modo escuro de verdade.

    13. Confirmação Antes de Excluir

    Atualize excluirMissao()
    www/js/index.jsfunction excluirMissao(indice) { const confirmou = confirm("Excluir esta missão?"); if (confirmou) { missoes.splice(indice, 1); desenharLista(); } }

    confirm() abre uma janelinha pronta do navegador com OK/Cancelar. O código só continua se a pessoa clicar em OK.

    14. Modo Detetive: 3 Erros de Propósito

    Erro 1 — array vs objeto

    missoes.push(texto); // guardando só o texto, sem { texto, feita }

    O app não quebra, mas missao.feita vira undefined em todo lugar, e missao.texto também — porque missao agora É o texto, não um objeto. Na tela aparece undefined em vez do texto digitado.

    Erro 2 — índice fora do array

    missoes.splice(missoes.length, 1); // tenta remover uma posição que não existe

    Não dá erro no Console, mas também não remove nada — splice simplesmente não encontra nada pra tirar naquela posição.

    Erro 3 — esqueceu o await/função

    botaoAdicionar.addEventListener('click', desenharLista()); // chamou a função em vez de passar ela

    Os parênteses depois de desenharLista fazem ela rodar na hora, uma vez só, em vez de esperar o clique. O jeito certo é () => { desenharLista(); } ou só desenharLista sem parênteses.

    Faça você: provoque cada um desses 3 erros de propósito no seu código, veja o que acontece, e desfaça (Ctrl+Z).

    15. Checklist Final

    • Adicionar missão funciona pelo botão e pela tecla Enter;
    • Excluir missão pede confirmação antes de remover;
    • Clicar no texto de uma missão risca ela (marca como concluída);
    • O contador mostra o número certo de pendentes;
    • A busca filtra a lista em tempo real;
    • O botão de ordenar organiza a lista em ordem alfabética;
    • O toggle de modo escuro muda o fundo do app.
