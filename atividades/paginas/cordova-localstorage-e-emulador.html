🧠 Ionic — LocalStorage e Emulador

Faça o app lembrar de tudo e veja ele rodando num Android de verdade

⏱️ Duração estimada: 1 hora e 30 minutos

Índice

    Pré-requisito: Ionic — Prática de JavaScript
    Tempo: ~1h30
    Formato: prática direta, pouca teoria

    1. O Plano de Hoje

    Duas partes: primeiro, fazer o app lembrar das missões (hoje elas somem quando você fecha a aba). Depois, a parte mais empolgante do curso — instalar e rodar o app dentro de um celular Android simulado.

    2. localStorage — Teste Rápido

    Abra o Console (F12) em qualquer página e digite, uma linha de cada vez:

    > localStorage.setItem('nome', 'Ana') > localStorage.getItem('nome') "Ana"

    setItem(chave, valor) guarda algo; getItem(chave) busca de volta. Recarregue a página e rode localStorage.getItem('nome') de novo — o valor continua lá, porque o localStorage sobrevive a recarregamentos e até a fechar o navegador.

    3. JSON.stringify e JSON.parse

    ⚠️ O localStorage só guarda texto — nunca um array ou objeto direto.
    teste no consoleconst lista = ["item 1", "item 2"]; const textoParaSalvar = JSON.stringify(lista); // vira '["item 1","item 2"]' localStorage.setItem('teste', textoParaSalvar); const textoSalvo = localStorage.getItem('teste'); const listaDeVolta = JSON.parse(textoSalvo); // vira array de novo: ["item 1", "item 2"]

    Regra simples: sempre que salvar, é stringify (array/objeto → texto); sempre que ler, é parse (texto → array/objeto de volta).

    4. Carregando as Missões Salvas

    Troque a linha do array no topo do index.js
    www/js/index.jslet missoes = JSON.parse(localStorage.getItem('minhas_missoes')) || [];

    Na primeira vez que o app roda, não existe nada salvo — getItem devolve null, e o || [] resolve isso começando com lista vazia em vez de quebrar.

    5. Salvando a Cada Mudança

    Adicione a primeira linha dentro de desenharLista()
    www/js/index.jsfunction desenharLista() { localStorage.setItem('minhas_missoes', JSON.stringify(missoes)); // salva sempre listaNaTela.innerHTML = ""; // ... resto da função continua igual ... }

    Como desenharLista() já é chamada depois de adicionar, excluir e marcar como concluída, colocando o setItem no início dela, o app salva sozinho em toda mudança.

    6. Testando a Persistência

    Faça você: adicione 3 missões, marque 1 como concluída, feche a aba completamente, abra de novo com cordova run browser. As 3 missões devem continuar lá, com a mesma marcada como concluída.

    Se sumiu tudo, confira se o nome 'minhas_missoes' está idêntico nos dois lugares (no getItem do capítulo 4 e no setItem do capítulo 5) — um espaço ou letra diferente já quebra.

    7. Salvando a Preferência de Tema

    Atualize o listener do toggle-tema
    www/js/index.jsconst toggleTema = document.getElementById('toggle-tema'); // carrega a preferência salva ao iniciar const temaEscuro = localStorage.getItem('tema_escuro') === 'true'; toggleTema.checked = temaEscuro; if (temaEscuro) { document.body.style.background = "#1a1a2e"; document.body.style.color = "#eee"; } toggleTema.addEventListener('ionChange', (evento) => { const ligado = evento.target.checked; document.body.style.background = ligado ? "#1a1a2e" : "#ffffff"; document.body.style.color = ligado ? "#eee" : "#333"; localStorage.setItem('tema_escuro', ligado); // salva a escolha });

    Repare: localStorage.getItem('tema_escuro') === 'true' — o localStorage guarda tudo como texto, então mesmo um valor "booleano" (verdadeiro/falso) vira a string "true" ou "false", e por isso comparamos com === 'true' em vez de usar o valor direto.

    8. Bônus: Contando as Visitas

    Código — cole em qualquer lugar do index.js
    www/js/index.jslet visitas = parseInt(localStorage.getItem('visitas')) || 0; visitas++; localStorage.setItem('visitas', visitas); console.log(`Esta é a visita número ${visitas}`);

    parseInt() transforma um texto em número (lembra que tudo no localStorage vira texto). Recarregue a página várias vezes e observe o número aumentar no Console.

    9. Abrindo o Android Studio

    1. Abra o Android Studio (já está instalado no computador).
    2. No menu, procure More Actions (ou o ícone de três pontinhos na tela inicial).
    3. Clique em Virtual Device Manager.

    10. Criando o Celular Virtual

    1. Clique em Create Device.
    2. Escolha o modelo Pixel 2 (tamanho de tela comum) e clique em Next.
    3. Escolha uma imagem do sistema, por exemplo Q (Android 10). Se pedir download, clique em Download e espere.
    4. Abra Show Advanced Settings e mude a RAM para 1500-2000 MB — evita travar o computador.
    5. Clique em Finish.

    11. Ligando o Celular Virtual

    Na lista do Virtual Device Manager, clique no botão Play (▶) ao lado do dispositivo que você criou. A primeira inicialização demora um pouco — é normal, é como ligar um celular novo pela primeira vez.

    🐢 Aproveite essa espera pra uma pausa rápida — vale muito nesse ponto do curso.

    12. Rodando o App no Emulador

    Com o celular virtual ligado, volte pro terminal, dentro da pasta meu-app:

    $ cordova platform add android $ cordova run android → instalando e abrindo o app no dispositivo...

    O primeiro comando (só uma vez) ensina o Cordova a construir pra Android. O segundo instala e abre o app dentro do celular virtual. Se tudo deu certo, o ícone "Minhas Missões" aparece no Android simulado, e o app abre igual ao que você viu no navegador — só que dentro de um celular.

    🎉 Seu app está rodando de verdade num Android simulado!

    13. Erros Comuns Nesta Fase

    O que aconteceuCausa provável
    As missões continuam sumindoO nome da chave ('minhas_missoes') está escrito diferente entre getItem e setItem
    Erro Unexpected token ao carregarAlguma coisa não-JSON foi salva sem JSON.stringify antes
    App não abre no emuladorO celular virtual não estava ligado quando rodou cordova run android, ou esqueceu o platform add android antes
    Muito lento / travandoRAM do celular virtual configurada alta demais pro seu computador — volte no Virtual Device Manager e reduza

    • As missões continuam salvas depois de fechar e abrir o navegador de novo;

    • Criei um celular virtual no Android Studio com RAM ajustada;
    • Rodei cordova platform add android e cordova run android com sucesso;
    • Vi o app "Minhas Missões" abrindo de verdade no celular simulado.
