Dia 03 — Produtividade e Acessibilidade no Windows 11

Aprimorar a organização pessoal, o uso de ferramentas de produtividade e conhecer recursos de acessibilidade do sistema.

1️⃣ Atividade 1: Usando o Bloco de Notas e o WordPad

Tarefa

  1. Abra o Bloco de Notas e escreva uma lista de tarefas do dia.
  2. Salve o arquivo como "tarefas.txt" na pasta Documentos.
  3. Abra o WordPad e escreva um pequeno texto com formatação (negrito, itálico, cor).
  4. Salve o arquivo como "texto_formatado.rtf".

Objetivo: Diferenciar editores simples e com formatação, e praticar o salvamento de arquivos.

2️⃣ Atividade 2: Usando o Agendador de Tarefas (Agenda/Calendário)

Tarefa

  1. Abra o aplicativo Calendário do Windows.
  2. Crie um novo evento chamado "Estudo de Windows" para o dia seguinte.
  3. Adicione um lembrete para 15 minutos antes do evento.
  4. Explore a integração com o e-mail (se disponível).

Objetivo: Aprender a organizar compromissos e lembretes.

3️⃣ Atividade 3: Explorando o Microsoft To Do

Tarefa

  1. Abra o aplicativo Microsoft To Do (ou instale pela Microsoft Store).
  2. Crie uma nova lista chamada "Estudos".
  3. Adicione 3 tarefas relacionadas ao curso.
  4. Marque uma delas como concluída.

Objetivo: Utilizar ferramentas de gerenciamento de tarefas pessoais.

4️⃣ Atividade 4: Acessibilidade no Windows 11

Tarefa

  1. Acesse Configurações > Acessibilidade.
  2. Ative o Narrador e explore como ele funciona.
  3. Teste o Lupa para ampliar partes da tela.
  4. Ative as Legendas ao vivo e veja como funcionam.

Objetivo: Conhecer recursos que tornam o sistema mais acessível para todos.

5️⃣ Atividade 5: Organização com Snap Layouts

Tarefa

  1. Abra dois aplicativos (ex: Bloco de Notas e Calculadora).
  2. Passe o mouse sobre o botão de maximizar e escolha um layout de divisão de tela.
  3. Organize os dois aplicativos lado a lado.
  4. Teste outro layout com três janelas abertas.

Objetivo: Aprender a organizar janelas para multitarefa eficiente.
